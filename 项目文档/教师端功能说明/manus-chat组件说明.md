# AI 课件助手 - 青少儿编程课件制作

## 功能特性

- ✅ 智能生成课程大纲
- ✅ 自动创建教学内容
- ✅ 生成适龄编程练习题
- ✅ 优化课件表达方式
- ✅ 实时流式响应（SSE）
- ✅ 步骤化显示生成过程
- ✅ 美观的对话界面

## 使用说明

### 1. 访问页面

在教师端导航菜单中，找到 **AI助手 > AI 课件助手** 即可进入。

### 2. 课件制作场景

#### 场景一：设计课程大纲
```
帮我设计一个适合8-10岁儿童的Scratch入门课程大纲，包含10节课
```

#### 场景二：生成教学内容
```
为Python变量这个知识点，创建一个适合12岁孩子的教学内容，要有趣味性
```

#### 场景三：创建练习题
```
为Python基础课程生成5个适合12岁孩子的编程练习题，难度递增
```

#### 场景四：优化课件
```
帮我优化这节课的教学内容，让它更适合青少儿理解：
[粘贴你的课件内容]
```

#### 场景五：设计趣味案例
```
创建一个关于循环结构的趣味教学案例，用游戏化方式讲解
```

### 3. 快速开始

页面提供了4个快速提问按钮，点击即可快速体验：
- 📚 设计 Scratch 入门课程大纲
- ✏️ 生成 Python 编程练习题
- 🎮 创建趣味教学案例
- ✨ 优化教学内容

### 4. 查看生成结果

AI 助手会以流式方式返回响应，实时显示生成过程：
- 每个步骤都会显示标签和内容
- 可以看到 AI 的思考和执行过程
- 错误信息会以红色标签显示

### 5. 输入技巧

- 按 `Enter` 键发送消息
- 按 `Shift + Enter` 换行
- 描述越详细，生成的内容越精准
- 可以指定年龄段、难度、主题等

### 6. 清空对话

点击右上角的 **清空对话** 按钮可以清空所有聊天记录，开始新的课件制作。

## 最佳实践

### 1. 明确目标受众
在提问时说明学生的年龄段，例如：
- "适合8-10岁儿童"
- "12岁左右的孩子"
- "初中生"

### 2. 指定编程语言
明确说明要使用的编程语言：
- Scratch
- Python
- JavaScript
- C++

### 3. 说明难度要求
- "入门级"
- "基础"
- "进阶"
- "难度递增"

### 4. 强调趣味性
青少儿编程需要趣味性，可以要求：
- "用游戏化方式"
- "结合生活场景"
- "有趣的例子"
- "互动性强"

### 5. 分步骤制作
复杂的课件可以分步骤制作：
1. 先生成课程大纲
2. 再为每个章节生成详细内容
3. 最后生成配套练习题

## 技术实现

> Agent SSE 接口详见 [Agent功能完整说明](Agent功能完整说明.md)

### 核心功能

1. **SSE 流式响应处理**
   - 使用 `fetch` + `ReadableStream` 实现
   - 支持实时接收和显示数据
   - 自动解析 SSE 格式数据

2. **步骤解析**
   - 自动识别 `Step X:` 格式
   - 识别错误信息和完成标记
   - 分类显示不同类型的消息

3. **UI 交互**
   - 自动滚动到最新消息
   - 加载状态提示
   - 流式响应动画效果
   - 快速提问按钮

## 注意事项

1. 确保已登录且具有教师角色权限
2. 每次调用都是独立的，不支持会话状态保持
3. 如需多轮对话，需要在消息中包含完整上下文
4. 接口超时时间为 5 分钟
5. 生成的内容仅供参考，请根据实际情况调整

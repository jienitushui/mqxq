# 教师端课程学生管理功能 — 技术深度解析

## 一、功能概述

教师端课程学生管理模块提供学员查看/移除、课程评论管理、浏览统计、作业发布/批改、仪表板统计、收入查看等功能，覆盖教师对学生学习全生命周期的管理。

### 学习状态机（MyCourse 生命周期）

> 完整的学习状态定义与流转图见 [公共参考-学习状态体系](../../公共参考/公共数据模型与基础配置.md#五学习状态体系my_course)。本模块特有：教师移除学员 → 删除 my_course 记录；新增章节/小节/作业 → 2→1 批量重置。

教师端涉及的状态触发：

| 操作 | 状态变化 | 触发服务 |
|------|---------|---------|
| 移除学员 | 删除 my_course | MyCourseTeacherServiceImpl |
| 新增章节 | 2→1 (批量) | ChapterServiceImpl |
| 新增小节 | 2→1 (批量) | SectionServiceImpl |
| 新增作业 | 2→1 (批量) | CourseHomeworkServiceImpl |

### 跨模块状态触发链

```
CourseViewServiceImpl.recordCourseView()
  → myCourseService.checkAndStartLearning()         // 0→1

CourseHomeworkServiceImpl.createHomework()
  → myCourseService.resetCompletedStatusToLearning() // 2→1

ChapterServiceImpl.createChapter()
  → myCourseService.resetCompletedStatusToLearning() // 2→1

SectionServiceImpl.createSection()
  → myCourseService.resetCompletedStatusToLearning() // 2→1
```

#### 关键函数

```
loadData()
├── api.getStudentsList({ page, size, ...searchForm })
│   → GET /api/teacher/my-course/students
├── 多重 fallback 解包: data.data / data.list / data.records
└── Promise.all 丰富学员数据

loadStatistics()
├── api.getMyStatistics()
│   → GET /api/teacher/my-course/my-statistics
└── 赋值 statistics (默认值 {1, 1, 5})

handleViewDetail(row)
├── api.getStudentDetail(row.id)
│   → GET /api/teacher/my-course/student-detail/{id}
├── 合并行数据 + 详情数据
└── 打开详情弹窗 (n-descriptions 2列)

handleRemoveStudent(id)
├── api.removeStudent(id)
│   → DELETE /api/teacher/my-course/remove-student/{id}
└── 刷新 loadData() + loadStatistics()

handleExport()
├── 需要先选择 courseId
├── api.exportStudents(courseId, params)
│   → GET /api/teacher/my-course/export-students/{courseId}
│   → responseType: 'blob'
└── 下载 .xlsx 文件
```

⚠ "总课程数"统计卡片错误显示 `%` 后缀（应为无后缀或"门"）。

## 三、后端执行流程

### 3.1 学员列表（`GET /api/teacher/my-course/students`）

```
请求参数: MyCourseQueryDTO { pageNum, pageSize, courseId?, studentName?, status?, teacherId(auto) }
│
┌─ Sa-Token 校验: @SaCheckRole("教师")
│
┌─ 步骤1: teacherId = SaUtil.getLoginId()  强制覆盖 DTO 的 teacherId
│
┌─ 步骤2: DAO 查询
│  └── myCourseDao.queryListByConditions(params)
│      SQL: SELECT mc.*, u.name, u.avatar, c.title, c.cover, t.name
│           FROM my_course mc
│           LEFT JOIN user u ON mc.user_id = u.id
│           LEFT JOIN course c ON mc.course_id = c.id
│           LEFT JOIN user t ON c.create_user = t.id
│           WHERE c.create_user = #{teacherId}    ← 教师归属过滤
│           [AND c.id = #{courseId}]
│           [AND u.name LIKE '%#{studentName}%']
│           [AND mc.status = #{status}]
│           ORDER BY mc.create_time DESC
│
└─ 返回 Result<PageInfo<MyCourseVO>>
    字段: id, userId, userNickname, userAvatar,
          courseId, courseName, courseCover, teacherName,
          orderId, status, createTime, updateTime
```

### 3.2 移除学员（`DELETE /api/teacher/my-course/remove-student/{myCourseId}`）

```
│
┌─ 步骤1: 加载 MyCourse 记录
│
┌─ 步骤2: 归属校验
│  └── myCourseService.checkTeacherCoursePermission(teacherId, courseId)
│      → course.getTeacherId().equals(teacherId)
│      → 不匹配 → MyException("无权操作")
│
┌─ 步骤3: 删除
│  └── myCourseDao.deleteById(myCourseId)  ← 硬删除
│
└─ 返回 Result<String>("移除成功")
```

### 3.3 教师统计（`GET /api/teacher/my-course/my-statistics`）

```
│
├── 查询教师所有课程列表
├── 统计: totalCourses (课程数)
├── 统计: totalStudents (学员数, DISTINCT user_id)
├── 统计: averageRating
│   └── courseCommentDao.getAverageRatingByCourseId(courseId) 逐课程求均
│       SQL: SELECT COALESCE(AVG(score), 0.0) FROM course_comment
│            WHERE course_id = #{courseId} AND status = 1
│
└─ 返回 Result<MyCourseStatisticsVO>
    字段: totalCourses, totalStudents, totalEnrollments,
          completedCourses, studyingCourses, activeStudents,
          completedStudents, completionRate, averageRating
```

### 3.4 学员导出（`GET /api/teacher/my-course/export-students/{courseId}`）

```
│
├── 归属校验: checkTeacherCoursePermission
│
├── 查询该课程全部学员 (无分页)
│
├── 构建 Excel:
│   ├── 列: userId, userName, courseId, courseName, status, joinTime, lastStudyTime
│   ├── 状态映射: 0=已加入, 1=学习中, 2=已完成
│   └── 写入临时文件
│
└── 流式输出到 HttpServletResponse
    Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
```

### 3.5 评论查询（`GET /api/teacher/comment/my-comments`）

```
请求参数: CommentQueryDTO { page, size, courseId?, score?, status?, keyword?, orderBy? }
│
┌─ Sa-Token 校验
│
├── DAO 查询:
│   courseCommentDao.queryCommentsForTeacher(params)
│   SQL: SELECT cc.*, c.title as courseName, u.name as userName, u.avatar
│        FROM course_comment cc
│        LEFT JOIN course c ON cc.course_id = c.id
│        LEFT JOIN user u ON cc.user_id = u.id
│        WHERE c.create_user = #{teacherId}       ← 教师归属
│        [AND cc.course_id = #{courseId}]
│        [AND cc.score = #{score}]
│        [AND cc.status = #{status}]
│        [AND (cc.content LIKE '%#{keyword}%'
│              OR u.name LIKE '%#{keyword}%')]
│        ORDER BY ${params.orderBy}                ← ⚠ SQL 注入风险
│
└─ 返回 Result<PageInfo<CommentVO>>
```

### 3.6 评论评分统计（`GET /api/teacher/comment/my-rating-statistics`）

```
│
├── 查询教师全部课程评论
├── 计算: totalComments, averageRating, totalCourses
├── 计算: recentComments (近 7 天)
│
└─ 返回 Result<CommentStatisticsVO>
    字段: totalComments, visibleComments, hiddenComments,
          todayComments, averageRating, recentComments, totalCourses
```

### 3.7 课程评分分布（`GET /api/teacher/comment/course-rating-statistics/{courseId}`）

```
│

│
├── courseCommentDao.getRatingStatisticsByCourseId(courseId)

│
└─ 返回 Result<CommentRatingVO>
    字段: totalComments, averageRating, ratingDistribution[5]
          (索引 0-4 对应 1-5 星数量)
```

## 四、前后端交互时序

### 教师查看学员完整流程

```
1. 加载学员列表
   my-course-students → onMounted → Promise.all
   │
   ├── GET /api/teacher/my-course/students?page=1&size=10
   │   → JOIN my_course + user + course, teacherId 过滤
   │   → 返回 PageInfo<MyCourseVO>
   │
   └── GET /api/teacher/my-course/my-statistics
       → 聚合统计: totalStudents, totalCourses, averageRating

2. 查看学员详情
   点击"查看详情" →
   ├── GET /api/teacher/my-course/student-detail/{id}
   │   → 归属校验 → 返回详情
   └── 打开 n-descriptions 弹窗

3. 移除学员
   点击"移除" → 确认弹窗 →
   ├── DELETE /api/teacher/my-course/remove-student/{id}
   │   → 归属校验 → 硬删除 my_course 记录
   └── 刷新列表 + 统计
```

### 作业批改完整流程

```
1. 教师创建作业
   homework → [发布作业] → 填写表单 →
   ├── POST /api/teacher/homework
   │   → 设置 createUser=teacherId, status=0
   │   → tryResetLearningStatus (已完成学员→学习中)
   └── 返回 CourseHomeworkVO

2. 学生提交作业 (学生端)
   → POST /api/user/homework-submission/submit
   → 校验: 已发布 + 未过期 + 已购课 + 无重复提交
   → homeworkSubmissionDao.insert

3. 教师批改
   grade → 选择作业 → 选择学生 →
   ├── GET /api/teacher/homework/submission/{id}
   │   → 返回提交内容 + 作业信息
   ├── 填写得分 + 评语 →
   ├── PUT /api/teacher/homework/submission/grade
   │   → score + teacherComment + gradeTime + status=1
   └── 刷新列表

4. 批量批改
   submission-manage → 勾选多条 →
   ├── PUT /api/teacher/homework-submission/batch-grade/{homeworkId}
   │   → { submissionIds, score, comment }
   └── 逐条更新
```

## 五、已知问题与风险点

> 跨模块系统级问题见 [公共参考-系统级已知问题与风险清单](../../公共参考/系统级已知问题与风险清单.md)，此处仅列本模块独有问题。

| # | 问题 | 严重度 | 说明 |
|---|---|---|---|
| 1 | **订单详情无归属校验** | 高 | 同[教师端数据大屏](教师端数据大屏功能-技术深度解析.md)文档，此处不重复 |
| 2 | **statistics/api.js BASE_URL 未定义** | 高 | 同[教师端作业](教师端作业功能-技术深度解析.md)文档，此处不重复 |
| 3 | **批改页客户端分页** | 中 | 同[教师端作业](教师端作业功能-技术深度解析.md)文档，此处不重复 |
| 4 | **收入数据不完整** | 中 | 后端仅返回 totalRevenue/totalOrders/completedOrders，前端自行映射 monthlyRevenue=totalRevenue, pendingRevenue=0，数据不真实 |
| 5 | **学员导出无分页限制** | 中 | 导出时查询课程全部学员（无 LIMIT），大课程可能导出数万行，内存/响应时间风险 |
| 6 | **评论回复 API 为死代码** | 低 | `POST /api/teacher/comment/{commentId}/reply` 已定义但 UI 无回复入口 |
| 7 | **作业发布 API 为死代码** | 低 | `PUT /api/teacher/homework/{id}/publish` 已定义但 UI 通过表单 status=1 替代 |
| 8 | **批改不触发完成状态检查** | 中 | 教师批改作业后不调用 `checkAndCompleteCourse()`，学生可能完成所有作业但状态仍为"学习中" |
| 9 | **学员统计卡片 % 后缀错误** | 低 | "总课程数"卡片错误显示 `%` 后缀，应为"门"或无后缀 |
| 10 | **收入页 viewOrderDetail 不完整** | 低 | 仅显示 JSON 字符串消息，无详情弹窗 |
| 11 | **归属校验字段不一致** | 中 | 部分服务用 `course.getCreateUser().equals(teacherId)`，部分用 `course.getTeacherId().equals(teacherId)`，若两字段不同则权限绕过 |
| 12 | **未提交学生查询无分页** | 低 | `getUnsubmittedStudents()` 返回全部未提交学生，大课程可能较多 |
| 13 | **收入 api.js 导入路径不同** | 低 | 使用 `@/utils/http` 而非其他页面的 `@/utils`，可能导致拦截器行为不一致 |

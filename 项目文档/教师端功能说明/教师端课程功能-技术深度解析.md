# 教师端课程功能 — 技术深度解析

## 一、功能概述

教师端课程模块提供课程创建/编辑/发布/下架、章节管理、小节管理（含视频上传）、课程评论查看、学员管理、浏览统计、AI 课件助手等功能，前端通过 vue-naive-admin 管理后台实现，后端通过独立的教师 Controller 提供接口，所有操作均验证课程归属。

### 课程数据层级

```
课程 (Course)                  ← teacher_id 归属
├── 章节 (Chapter)              ← 通过 course_id 关联课程
│   ├── 小节 (Section)          ← 通过 chapter_id + course_id 关联
│   │   ├── videoUrl            ← 视频文件（MinIO 存储）
│   │   ├── content             ← 小节文字内容
│   │   ├── duration            ← 视频时长（秒）
│   │   └── status              ← 0=未发布, 1=已发布
│   └── ...
├── 课程分类 (CourseSubject)    ← 通过 subject_id 关联（管理员管理）
├── 课程评论 (CourseComment)    ← 学生评价（教师只读）
└── 浏览记录 (CourseView)       ← 访问追踪
```

### 教师 vs 管理员权限对比

| 维度 | 教师 | 管理员 |
|---|---|---|
| 课程列表 | 仅自己课程 | 全部课程 |
| 创建课程 | teacherId 自动填充 | 手动选择 teacherId |
| 课程分类 | 仅引用（公共 API 获取树） | 完整 CRUD |
| 章节批量删除 | 不可用 | `DELETE /batch` |
| 小节批量删除 | 不可用 | `DELETE /batch` |
| 删除课程 | 已发布课程不可删 | 可删除任意课程 |
| 评论管理 | 只读 + 导出 | 隐藏/显示/删除/批量操作 |
| 学员管理 | 查看 + 移除 | 强制退出 + 批量退出 |
| 课程统计 | 有 | 有（更详细） |
| AI 助手 | 有 | 无 |

#### 课程封面图上传

```
n-upload 组件:
├── action: "/api/public/files/image"
├── accept: "image/*", max: 1
├── list-type: "image-card"
│
├── handleBeforeUpload:
│   ├── 非图片类型 → $message.warning
│   └── size > 5MB → $message.warning
│
├── handleUploadFinish:
│   ├── response = event.target.response  ← ⚠ 直接是 URL 字符串，非 JSON

    ├── deleteFileFromServer(coverUrl)

## 三、后端执行流程

### 3.1 Sa-Token 认证架构

> 认证架构详见 [公共参考-认证与权限体系](../../公共参考/公共数据模型与基础配置.md#二认证与权限体系sa-token)

### 3.2 创建课程（`POST /api/teacher/course`）

```
请求体: CreateCourseDTO {
  title (@NotBlank, 1-100),
  description (@NotBlank, 1-500),
  subjectId (@NotNull, @Min(1)),
  price (@NotNull, @DecimalMin("0.00")),
  cover (可选),
  lessonNum, durationSum
  teacherId (@NotNull) ← ⚠ 教师端忽略此字段
}
│
┌─ Sa-Token 校验: @SaCheckRole("教师")
│
┌─ 步骤1: 获取 teacherId
│  └── teacherId = SaUtil.getLoginId()  ← 覆盖 DTO 中的 teacherId
│
┌─ 步骤2: 构建课程实体
│  ├── Course course = new Course()
│  ├── 设置所有 DTO 字段 + teacherId
│  ├── course.setStatus(0)              ← 默认未发布
│  ├── course.setBuyCount(0)
│  └── course.setViewCount(0)
│
┌─ 步骤3: 入库
│  └── courseDao.insert(course)
│
┌─ 步骤4: AI 向量库同步
│  └── courseVectorSyncService.addCourseToVectorStore(course)
│      → 将课程信息嵌入 Elasticsearch（text-embedding-v3）
│
└─ 返回 Result<CourseDetailVO>
    含完整课程信息 + teacherName
```

### 3.3 更新课程（`PUT /api/teacher/course/{id}`）

```
请求体: UpdateCourseDTO (所有字段可选)
│
┌─ 归属校验: course.getTeacherId().equals(teacherId)
│   └── 失败 → MyException("无权修改此课程")
│
┌─ 部分更新: 仅设置 DTO 中非 null 字段
│
├─ AI 向量库同步:
│   └── courseVectorSyncService.updateCourseInVectorStore(course)
│
└─ 返回 Result<CourseDetailVO>
```

### 3.4 发布课程（`PUT /api/teacher/course/{id}/publish`）

```
│
┌─ 归属校验
│
┌─ 发布前检查: canPublishCourse(courseId)
│   ├── title 为空 → 不通过
│   ├── description 为空 → 不通过
│   ├── cover 为空 → 不通过
│   └── 任一不满足 → MyException("课程信息不完整，无法发布")
│
┌─ 更新状态
│   ├── course.setStatus(1)             ← 已发布
│   └── course.setPublishTime(new Date())
│
├─ AI 向量库同步: addCourseToVectorStore
│
└─ 返回 Result<Void>
```

⚠ 发布检查仅验证 title/description/cover，不检查是否有章节和小节，空课程也可发布。

### 3.5 下架课程（`PUT /api/teacher/course/{id}/unpublish`）

```
│
┌─ 归属校验
│
├─ course.setStatus(0)                 ← 未发布
│
├─ AI 向量库: deleteCourseFromVectorStore(courseId)
│
└─ 返回 Result<Void>
```

### 3.6 删除课程（`DELETE /api/teacher/course/{id}`）

```
│
┌─ 归属校验
│
┌─ ⚠ 已发布课程不可删除:
│   └── course.getStatus() == 1 → MyException("已发布的课程不能删除，请先取消发布")
│
├─ AI 向量库: deleteCourseFromVectorStore(courseId)
│
└─ courseDao.deleteById(id)
    ⚠ 硬删除，不级联删除章节/小节
    ⚠ 章节/小节成为孤立数据
```

### 3.7 创建章节（`POST /api/teacher/chapter`）

```
请求体: ChapterCreateDTO {
  courseId (@NotNull, @Min(1)),
  title (@NotBlank, 1-200)
}
│
┌─ 归属校验: verifyCourseOwnership(courseId, teacherId)
│
┌─ 步骤1: 校验课程存在
│
┌─ 步骤2: 入库
│   └── chapterDao.insert(chapter)
│
├─ 步骤3: ⚠ 学习状态重置
│   └── tryResetLearningStatus(courseId, "添加了新章节")
│       → myCourseService.resetCompletedStatusToLearning(courseId)
│       → 已完成学员状态 2→1（已完成→学习中）
│
└─ 返回 Result<ChapterVO>
```

### 3.8 删除章节（`DELETE /api/teacher/chapter/{id}`）

```
│
┌─ 归属校验: verifyChapterOwnership(id, teacherId)
│
├─ ⚠ 级联删除:
│   ├── 先删除该章节下所有小节
│   │   └── sectionService.deleteSection(sectionId) 逐个删除
│   └── 再删除章节本身
│       └── chapterDao.deleteById(id)
│
└─ 返回 Result<Void>
    ⚠ 小节删除不触发学习状态重置（与添加小节不同）
```

### 3.9 创建小节（`POST /api/teacher/section`）

```
请求体: SectionCreateDTO {
  chapterId (@NotNull), courseId (@NotNull),
  title (@NotBlank, max 200), content (max 5000),
  videoUrl (max 500), duration (@Min(0)), status (@Min(0))
}
│
┌─ 归属校验: verifyCourseOwnership(courseId, teacherId)
│
┌─ 章节-课程匹配校验:
│   └── verifyChapterCourseMat(chapterId, courseId)
│       → chapter.getCourseId().equals(courseId) 否则抛异常
│
┌─ 默认 status = 0（未发布）
│

### 教师创建课程+章节+小节完整流程

```
1. 创建课程
   teacherhome/course → [新增] → 填写表单 + 上传封面
   │
   ├── POST /api/public/files/image  → MinIO → 返回 URL
   ├── POST /api/teacher/course { title, description, subjectId, price, cover }
   │   ├── 后端: teacherId = SaUtil.getLoginId()
   │   ├── 后端: courseDao.insert + 向量库同步
   │   └── 返回 CourseDetailVO
   └── 课程列表刷新

2. 管理章节
   点击"章节" → /teacherhome/chapter?courseId=1&courseName=xxx
   │
   ├── POST /api/teacher/chapter { courseId:1, title:"第一章" }
   │   ├── 后端: 归属校验 + chapterDao.insert
   │   ├── 后端: tryResetLearningStatus (已完成的学员→学习中)
   │   └── 返回 ChapterVO
   └── 章节列表刷新

3. 管理小节
   点击"小节管理" → /teacherhome/section?chapterId=1&courseId=1
   │
   ├── POST /api/public/files/video  → MinIO → 返回 URL
   ├── POST /api/teacher/section { chapterId:1, courseId:1, title:"1.1", videoUrl, duration:300 }
   │   ├── 后端: 归属校验 + 章节课程匹配校验
   │   ├── 后端: sectionDao.insert + tryResetLearningStatus
   │   └── 返回 SectionVO
   └── 小节列表刷新

4. 发布课程
   点击"发布" → PUT /api/teacher/course/1/publish
   │
   ├── 后端: canPublishCourse → title/description/cover 非空检查
   ├── 后端: setStatus(1) + setPublishTime + 向量库同步
   └── 课程列表刷新
```

## 五、已知问题与风险点

> 跨模块系统级问题见 [公共参考-系统级已知问题与风险清单](../../公共参考/系统级已知问题与风险清单.md)，此处仅列本模块独有问题。AI模块问题详见 [教师端AI教案功能](./教师端AI教案功能-技术深度解析.md#五已知问题与风险点)

| # | 问题 | 严重度 | 说明 |
|---|---|---|---|
| 1 | **课程删除不级联** | 高 | 教师删除课程时仅删 course 记录，章节和小节成为孤立数据（管理员删除同理） |
| 2 | **发布检查不验证章节/小节** | 中 | 仅检查 title/description/cover 非空，空课程（无章节无小节）也可发布上线 |
| 3 | **文件上传响应非 JSON** | 中 | `/api/public/files/image|video` 返回纯 URL 字符串，前端通过 `event.target.response` 读取，与项目其他 API 的 `Result<T>` 格式不一致 |
| 4 | **文件删除使用原生 fetch** | 低 | `deleteFileFromServer` 不走 Axios 拦截器，Token 不会被自动附加（依赖浏览器 Cookie） |
| 5 | **视频上传无进度条** | 低 | 大视频上传（100MB 限制）无进度反馈，用户体验差 |
| 6 | **章节无排序字段** | 中 | 章节表无 sort_order 字段，仅按 create_time DESC 排序，无法手动调整顺序 |
| 7 | **小节排序按 ID 升序** | 低 | `ORDER BY chapter_id ASC, id ASC`，无法手动调整小节播放顺序 |
| 8 | **添加章节/小节重置学员状态** | 中 | 已完成学员被强制退回"学习中"，学员进度体验差，应更精细地标记"有新内容"而非重置 |
| 9 | **课程分类仅管理员可管理** | 低 | 教师无法创建/编辑课程分类，需依赖管理员 |
| 10 | **RichTextEditor 组件未使用** | 低 | 项目有自定义富文本编辑器组件，但课程描述使用普通 textarea |
| 11 | **小节视频 MIME 不校验** | 低 | 后端仅检查扩展名（MP4/AVI/MOV），不验证实际文件内容，可上传伪装文件 |
| 12 | **封面/视频删除先于表单提交** | 中 | 用户在表单中删除已上传文件后若取消编辑，MinIO 中文件已删但实体仍引用旧 URL |

# 教师端数据大屏设计方案

## 一、核心指标卡片（顶部展示）

### 1.1 课程相关指标
- **我的课程总数**：`COUNT(course WHERE teacher_id = ?)`
- **已发布课程数**：`COUNT(course WHERE teacher_id = ? AND status = 1)`
- **未发布课程数**：`COUNT(course WHERE teacher_id = ? AND status = 0)`
- **课程总浏览量**：`SUM(course.view_count WHERE teacher_id = ?)`
- **课程总销售额**：`SUM(orders.goods_price WHERE course.teacher_id = ? AND orders.status = 'DONE')`
- **课程平均评分**：`AVG(course_comment.score WHERE teacher_id = ?)`
- **课程评论总数**：`COUNT(course_comment WHERE teacher_id = ?)`

### 1.2 学员相关指标
- **总学员数**：`COUNT(DISTINCT my_course.user_id WHERE course.teacher_id = ?)`
- **学习中学员数**：`COUNT(my_course WHERE course.teacher_id = ? AND my_course.status = 1)`
- **已完成学员数**：`COUNT(my_course WHERE course.teacher_id = ? AND my_course.status = 2)`
- **已加入学员数**：`COUNT(my_course WHERE course.teacher_id = ? AND my_course.status = 0)`
- **学员完成率**：`已完成学员数 / 总学员数 * 100%`

### 1.3 作业相关指标
- **作业总数**：`COUNT(course_homework WHERE create_user = ?)`
- **已发布作业数**：`COUNT(course_homework WHERE create_user = ? AND status = 1)`
- **待批改作业数**：`COUNT(homework_submission WHERE course_homework.create_user = ? AND homework_submission.status = 0)`
- **已批改作业数**：`COUNT(homework_submission WHERE course_homework.create_user = ? AND homework_submission.status = 1)`
- **作业平均分**：`AVG(homework_submission.score WHERE course_homework.create_user = ?)`

### 1.4 收入相关指标
- **今日收入**：`SUM(orders.goods_price WHERE course.teacher_id = ? AND orders.status = 'DONE' AND DATE(orders.pay_time) = CURDATE())`
- **本月收入**：`SUM(orders.goods_price WHERE course.teacher_id = ? AND orders.status = 'DONE' AND MONTH(orders.pay_time) = MONTH(NOW()))`
- **累计总收入**：`SUM(orders.goods_price WHERE course.teacher_id = ? AND orders.status = 'DONE')`
- **今日订单数**：`COUNT(orders WHERE course.teacher_id = ? AND orders.status = 'DONE' AND DATE(orders.pay_time) = CURDATE())`

## 五、数据库查询示例

### 1. 课程销售排行
```sql
SELECT
    c.id AS courseId,
    c.title AS courseName,
    c.cover AS courseImg,
    COUNT(o.id) AS orderCount,
    SUM(o.goods_price) AS totalRevenue
FROM orders o
INNER JOIN course c ON o.goods_id = c.id
WHERE c.teacher_id = ? AND o.status = 'DONE'
GROUP BY c.id, c.title, c.cover
ORDER BY orderCount DESC, totalRevenue DESC
LIMIT 10;
```

### 2. 学员学习状态统计
```sql
SELECT
    mc.status,
    COUNT(*) AS count
FROM my_course mc
INNER JOIN course c ON mc.course_id = c.id
WHERE c.teacher_id = ?
GROUP BY mc.status;
```

### 3. 收入趋势（按日期）
```sql
SELECT
    DATE(o.pay_time) AS date,
    SUM(o.goods_price) AS revenue
FROM orders o
INNER JOIN course c ON o.goods_id = c.id
WHERE c.teacher_id = ?
    AND o.status = 'DONE'
    AND o.pay_time >= DATE_SUB(NOW(), INTERVAL 30 DAY)
GROUP BY DATE(o.pay_time)
ORDER BY date ASC;
```

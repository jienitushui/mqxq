#### 🎯 核心 API 使用示例

### 示例 1：简单对话

```typescript
import { chatApi } from '@/api/chat'

// 1. 创建会话
const session = await chatApi.createSession()

// 2. 发送消息
let response = ''
await chatApi.chat(
  {
    question: '你好',
    sessionId: session.sessionId
  },
  (data) => {
    response += data
    console.log('AI 回复:', response)
  }
)
```

### 示例 2：带停止功能的对话

```typescript
import { ref } from 'vue'
import { chatApi } from '@/api/chat'

const isGenerating = ref(false)
const currentSessionId = ref('')
let cancelFn: (() => void) | null = null

// 发送消息
const sendMessage = async (question: string) => {
  isGenerating.value = true
  
  cancelFn = await chatApi.chat(
    { question, sessionId: currentSessionId.value },
    (data) => console.log(data),
    undefined,
    (error) => console.error(error),
    () => {
      isGenerating.value = false
      cancelFn = null
    }
  )
}

// 停止生成
const stopGeneration = () => {
  if (cancelFn) {
    cancelFn()
    cancelFn = null
  }
  chatApi.stop(currentSessionId.value)
  isGenerating.value = false
}
```

```typescript
import { watch } from 'vue'

// 监听消息变化，保存到 localStorage
watch(messages, (newMessages) => {
  localStorage.setItem(
    `chat_${currentSessionId.value}`,
    JSON.stringify(newMessages)
  )
}, { deep: true })

// 加载时恢复消息
const loadMessages = (sessionId: string) => {
  const saved = localStorage.getItem(`chat_${sessionId}`)
  if (saved) {
    messages.value = JSON.parse(saved)
  }
}
```

#### 🐛 故障排查

### 问题 1：聊天按钮不显示

检查：
1. 是否正确导入组件
2. 是否有 CSS 冲突
3. 检查 z-index 是否被覆盖

### 问题 2：无法发送消息

检查：
1. 是否已登录（需要 token）
2. API 地址是否正确
3. 后端服务是否正常
4. 浏览器控制台是否有错误

### 问题 3：消息不流式显示

检查：
1. 后端是否返回 SSE 格式
2. Content-Type 是否为 `text/event-stream`
3. 是否有代理服务器缓存了响应

### 问题 4：历史消息加载失败

检查：
1. sessionId 是否正确
2. 是否有权限访问该会话
3. 后端接口是否正常

```typescript
  for (let i = 0; i < maxRetries; i++) {
    try {
      await chatApi.chat(params, onMessage)
      break
    } catch (error) {
```

### 2. API 接口 (`src/api/chat.ts`)

完整的聊天 API 封装：

#### 会话管理
- `createSession(n)` - 创建新会话
- `getHotExamples(n)` - 获取热门示例
- `getSessionList()` - 获取会话列表
- `getSessionMessages(sessionId)` - 获取历史消息
- `deleteSession(sessionId)` - 删除会话

#### 聊天功能
- `chat(params, onMessage, onParam, onError, onComplete)` - 流式聊天
  - 支持 SSE 流式响应
  - 处理三种事件类型（DATA, STOP, PARAM）
  - 返回取消函数
- `stop(sessionId)` - 停止 AI 输出

#### 🔄 完整流程示例

### 新用户首次对话

```
1. 用户点击悬浮按钮
   ↓
2. 调用 createSession() 创建会话
   ← 返回 sessionId 和示例问题
   ↓
3. 用户选择示例或输入问题
   ↓
4. 调用 chat() 发送消息（流式）
   ← 实时接收 AI 回复（DATA 事件）
   ← 可能接收工具参数（PARAM 事件）
   ← 接收结束标记（STOP 事件）
   ↓
5. 会话自动保存到数据库（后端）
   ↓
6. 用户可以继续对话（使用相同 sessionId）
```

### 查看历史对话

```
1. 用户打开聊天页面
   ↓
2. 调用 getSessionList() 获取会话列表
   ← 返回所有历史会话
   ↓
3. 用户选择一个会话
   ↓
4. 调用 getSessionMessages(sessionId) 获取历史
   ← 返回该会话的所有消息
   ↓
5. 显示历史消息
   ↓
6. 用户可以继续对话
```

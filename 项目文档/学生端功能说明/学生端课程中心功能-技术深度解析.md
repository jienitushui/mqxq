# 学生端课程中心功能 — 技术深度解析

## 一、功能概述

学生端课程中心是码趣星球平台的核心模块，涵盖课程浏览、搜索、详情、学习、购买/加入及评论等全链路功能。前端通过 `courseApi.ts` 智能切换 `publicApi`/`userApi`，实现免登录浏览与登录后个性化体验的无缝衔接。

### 功能清单

| 功能 | 前端页面/组件 | 后端端点 | 认证要求 |
|---|---|---|---|
| 课程列表（分页） | CourseList.vue | `GET /api/public/course/page` | 否 |
| 课程搜索 | CourseList.vue / Search.vue | `GET /api/public/course/search`（title 参数） | 否 |
| 分类筛选 | CourseList.vue | `GET /api/public/course/page`（subjectId） | 否 |
| 免费课程 | CourseList.vue | `GET /api/public/course/free` | 否 |
| 热门课程 | CourseList.vue 侧栏 | `GET /api/public/course/hot` | 否 |
| 课程详情（公共） | CourseDetail.vue | `GET /api/public/course/{id}` | 否 |
| 课程详情（个性化） | CourseDetail.vue | `GET /api/user/course/{id}` | `@SaCheckRole("用户")` |
| 课程分类树 | CourseList.vue 下拉框 | `GET /api/public/course-subject/tree` | 否 |
| 课程学习 | CourseLearn.vue | `GET /api/user/course/can-study/{courseId}`（⚠ 未调用）+ `GET /api/user/my-course/detail/{courseId}` | `@SaCheckRole("用户")` |
| 章节结构 | CourseChapters.vue | `GET /api/public/chapter-section/course/{courseId}/structure` | 否 |
| 加入课程 | CourseDetail.vue | `POST /api/user/my-course/join` | `@SaCheckRole("用户")` |
| 我的课程列表 | MyCourses.vue | `GET /api/user/my-course/list` | `@SaCheckRole("用户")` |
| 我的课程详情 | MyCourses.vue | `GET /api/user/my-course/detail/{courseId}` | `@SaCheckRole("用户")` |
| 学习进度更新 | CourseLearn.vue | `PUT /api/user/my-course/progress`（⚠ 未调用） | `@SaCheckRole("用户")` |
| 退出课程 | ⚠ 无 UI 入口 | `DELETE /api/user/my-course/quit/{courseId}` | `@SaCheckRole("用户")` |
| 课程评论 | CourseComments.vue | `GET /api/public/comment/course/{courseId}` | 否（列表） |
| 发表评论 | CourseComments.vue | `POST /api/user/comment` | `@SaCheckLogin` |
| 记录浏览 | CourseDetail.vue（⚠ 仅 console.log 占位） | `POST /api/user/course/{id}/view` | `@SaCheckRole("用户")` |
| AccessModal | AccessModal.vue | — | 前端组件，引导登录/购买/加入 |

### 三级访问模型

课程内容按层级实施不同的访问控制：

| 层级 | 条件 | 可访问内容 | 不可访问时 |
|---|---|---|---|
| **免费试看** | 无需任何条件 | 课程基本信息 + 免费小节内容 | 无 |
| **登录用户** | 已登录 + 用户角色 | 个性化信息（购买/加入状态） | 弹出 AccessModal（登录类型） |
| **已购/已加入** | 完成购买或加入 | 全部课程内容 + 学习进度 | 弹出 AccessModal（购买/加入类型） |

### courseApi.ts 双 API 智能切换

前端课程模块的核心设计 — 根据 `isAuthenticated` 状态自动选择 `publicApi` 或 `userApi`，并在 `userApi` 失败时 fallback 回 `publicApi`：

```typescript
// courseApi.ts 核心模式
const getCourseDetail = async (id: number) => {
  try {
    if (isAuthenticated.value) {
      return await userApi.getCourseDetail(id)   // 个性化详情
    }
    return await publicApi.getCourseDetail(id)     // 未登录
  } catch {
    if (isAuthenticated.value) {
      return await publicApi.getCourseDetail(id)   // fallback
    }
    throw error  // 未登录时 publicApi 失败直接抛出
  }
}
```

**适用场景**：课程详情使用此模式。课程列表仅使用 `publicApi`（不涉及 userApi 分支），章节结构、评论列表等纯公共数据直接走 `publicApi`。

### 2.4 AccessModal 组件（AccessModal.vue）

三种弹出类型，通过 props/emits 控制的调用模式：

```typescript
// 调用方式
const accessModal = ref({ visible: false, type: 'login' })

// 登录引导
accessModal.value = { visible: true, type: 'login' }

// 购买引导
accessModal.value = { visible: true, type: 'purchase', courseInfo: { courseId, price, title } }

// 加入引导
accessModal.value = { visible: true, type: 'join', courseInfo: { courseId } }

// Promise 通过调用方在 accessModal ref 上挂载 resolve 实现
// 用户完成操作后调用 resolve()，关闭时调用 reject()
```

#### 三种类型 UI

| 类型 | 标题 | 内容 | 操作 |
|---|---|---|---|
| `login` | "需要登录" | 登录提示 + 功能说明 | "立即登录" → 跳转 `/auth/login` |
| `purchase` | "需要购买课程" | 课程名 + 价格 + 支付说明 | "立即购买" → 跳转支付 |
| `join` | "加入课程" | 课程名 + 免费说明 | "立即加入" → `joinCourse()` API |

**Promise 设计**：`show()` 返回 Promise，用户完成操作后 resolve，关闭时 reject。调用方可在 `.then()` 中执行后续逻辑（如刷新详情、开始播放）。

### 3.7 浏览记录（`POST /api/user/course/{id}/view`）

```
│
┌─ Sa-Token 校验: @SaCheckRole("用户")
│
┌─ 步骤1: 查询课程
│  └── courseDao.queryById(id) + status 检查
│
┌─ 步骤2: 递增浏览量（⚠ 非原子操作）
│  ├── int currentCount = course.getViewCount()
│  ├── course.setViewCount(currentCount + 1)
│  └── courseDao.update(course)
│       SQL: UPDATE course SET view_count = #{viewCount} WHERE id = #{id}
│
└─ 返回 Result.success("浏览记录已更新")
```

**并发风险**：读-改-写非原子操作，两个并发请求可能读到相同的 `viewCount`，导致最终仅 +1 而非 +2。应改为 `SQL: UPDATE course SET view_count = view_count + 1 WHERE id = #{id}`。

## 五、已知问题与风险点

> 跨模块系统级问题见 [公共参考-系统级已知问题与风险清单](../../公共参考/系统级已知问题与风险清单.md)，此处仅列本模块独有问题。

| # | 问题 | 严重度 | 说明 |
|---|---|---|---|
| 1 | **浏览量非原子递增** | 高 | `viewCount = queryById().getViewCount() + 1; update()` 为读-改-写非原子操作，并发下丢失递增，应改为 `SET view_count = view_count + 1` |
| 2 | **免费课程可直接加入绕过购买** | 中 | 免费课程 `canStudy=true` 且 `joinCourse` 不检查订单，但付费课程加入需已完成订单；免费课程加入路径不经过支付，逻辑正确但需确认业务意图 |
| 3 | **章节 videoUrl 公开返回** | 中 | `GET /api/public/chapter-section/course/{courseId}/structure` 免登录返回完整 videoUrl，未购买用户可直接拼接地址访问付费视频 |
| 4 | **进度完成判定简化** | 低 | `progress >= 100` 判定完成，但进度值由前端上报，可被篡改 |
| 5 | **评论仅限已加入用户** | 低 | 评论需先加入课程，已购买但未加入的用户无法评论 |
| 6 | **免费筛选双重路径** | 低 | CourseList.vue 对 `freeOnly` 走独立 `/free` 端点而非在 `/page` 加 `price=0` 条件，API 路径冗余 |
| 7 | **视频 MIME 类型依赖浏览器** | 低 | HTML5 video 不指定 source type，依赖浏览器自动识别，部分格式可能不兼容 |
| 8 | **courseApi.ts fallback 吞噬错误** | 低 | userApi 失败后静默 fallback 到 publicApi，可能掩盖真实错误（如 403 权限问题被当作"未登录"处理） |
| 9 | **课程列表 userApi 无个性化差异** | 低 | 课程列表（非详情）userApi 与 publicApi 返回数据结构一致，登录与否对列表页无实质差异，4 分支选择增加复杂度但无收益 |

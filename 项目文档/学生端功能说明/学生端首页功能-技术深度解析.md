# 学生端首页功能 — 技术深度解析

## 一、功能概述

学生端首页是码趣星球在线学习平台的入口页面，面向所有用户（含未登录访客）展示平台核心内容。页面由 5 个独立区块组成，通过 4 个并行公共 API 加载数据。

### 页面区块一览

| 区块 | 数据来源 | 认证要求 | 说明 |
|---|---|---|---|
| 搜索栏 | 无（纯导航） | 否 | 输入关键词跳转搜索页 |
| 轮播图 | `GET /api/public/carousel/homepage` | 否 | 最多 5 张，带标题/描述/按钮 |
| 公告栏 | `GET /api/public/announcements/latest` | ⚠ 需登录 | 最新 6 条公告 |
| 课程分类 | `GET /api/public/course-subject/tree` | 否 | 两级树形分类导航 |
| 热门课程 | `GET /api/public/course/hot` | 否 | 按浏览量取 8 门课程 |

### 技术栈关键点

- **前端**：Vue 3 + Element Plus（el-carousel/el-input）+ Tailwind CSS + Pinia
- **后端**：Spring Boot 3.2 + MyBatis（PageHelper 分页）+ Sa-Token + MySQL
- **公共 API 前缀**：`/api/public/`（大部分免登录，公告相关需 `@SaCheckRole("用户")`）

### 2.2 数据加载流程

页面挂载时通过 `Promise.all` 并行加载 4 组数据：

```typescript
const initPageData = async () => {
  await Promise.all([
    fetchBannerList(),      // 轮播图
    fetchCategories(),      // 课程分类
    fetchPopularCourses(),  // 热门课程
    fetchAnnouncements()    // 公告
  ])
}
```

每组数据独立管理 loading 状态（`loading.banner`/`loading.categories`/`loading.announcements`/`loading.courses`），互不阻塞。

#### 轮播图数据流

```
GET /api/public/carousel/homepage?limit=5
  → Carousel[] 
  → map() 合并 defaultBannerTexts 兜底文案（title/description/buttonText 缺失时使用预设值）
  → bannerList ref
  → el-carousel v-for 渲染（背景图 + 渐变遮罩 + 文字）
```

预设兜底文案数组（5 条）：
```typescript
const defaultBannerTexts = [

  { title: '实战项目驱动', description: '理论结合实践，快速提升能力', buttonText: '了解更多' },
  { title: '随时随地学习', description: '灵活安排时间，高效掌握知识', buttonText: '立即加入' },
]
```

#### 课程分类数据流

```
GET /api/public/course-subject/tree
  → CourseSubject[]（API 已返回树形结构）
  → filter(parentId === 0) → categories ref（仅取顶级分类）
  → 自动选中第一个：activeTopCategoryId + activeCategory
  → 顶级分类渲染为水平胶囊按钮
  → 选中分类的 children 渲染为响应应网格卡片
  → 点击子分类 → router.push('/courses?subjectId={id}')
```

分类展开/收起逻辑：`toggleTopCategory(id)` — 点击已展开的则收起，点击新的则切换。

#### 热门课程数据流

```
GET /api/public/course/hot?limit=8
  → Course[]
  → popularCourses ref
  → 4 列响应应网格，内联课程卡片（非 CourseCard.vue 组件）
  → 点击 → router.push('/courses/{id}')
```

课程卡片内联渲染字段：
| 字段 | 显示 | 备注 |
|---|---|---|
| `cover` | 封面图 | object-cover, h-48 |
| `status === 1` | 红色 "热门" 标签 | 仅状态为1时显示 |
| `title` | 标题 | line-clamp-2 |
| `description` | 描述 | line-clamp-2 |
| `buyCount` | X人购买 | |
| `lessonNum` | X课时 | |
| `durationSum / 60` | X分钟 | 取整 |
| `price` | 价格 | 红色 |
| `viewCount` | X次游览 | |

#### 公告数据流

```
GET /api/public/announcements/latest?count=6
  → Announcement[]
  → announcements ref
  → 列表项：分类标签(categoryName || "公告") + 标题 + 日期(publishDate)
  → 点击 → router.push('/announcements/{id}')
  → "查看更多" → router.push('/announcements')
```

### 2.3 搜索功能

```typescript
const handleSearch = async () => {
  if (searchKeyword.value.trim()) {
    router.push({ path: '/search', query: { q: searchKeyword.value.trim() } })
  }
}
```

首页不做搜索 API 调用，仅将关键词作为 query 参数跳转到 `/search` 页面。支持回车键和按钮点击触发。

### 2.4 导航栏（Navbar.vue）

粘顶布局（z-index 1000，高 64px，max-width 1200px 居中），auth 条件渲染：

| 状态 | 导航项 | 右侧操作 |
|---|---|---|
| 未登录 | 首页/课程/公告 | "登录"(outline) + "注册"(primary) 按钮 |
| 已登录 | 首页/课程/公告/我的学习/作业/我的订单 | 用户头像下拉（个人中心/设置/退出） |

移动端（≤768px）：汉堡菜单 → 固定覆盖层展开，下拉菜单变为静态展示。

### 2.5 AI 聊天悬浮助手（AIChatAssistant.vue）

**Auth 门控**：
- 未登录：人形图标 + "登录后开始聊天"，点击跳转登录页
- 已登录：聊天气泡图标 + "有问题？问我吧！"，点击展开聊天窗

**聊天流程**（SSE 流式）：
```
用户点击 FAB → initSession()
├── chatApi.createSession(3) → { sessionId, title, describe, examples[] }
│
用户输入/点击示例 → 发送消息
├── chatApi.chat({ question, sessionId }, onMessage, onParam, onError, onComplete)
│   ├── onMessage: 逐块追加 AI 回复文本
│   ├── onParam: 工具调用参数（课程推荐/订单信息）
│   ├── onError: 添加错误消息
│   └── onComplete: 重置 loading 状态
│
支持中断：cancelChat() + chatApi.stop(sessionId)
```

**窗口特性**：默认 680×700px，可拖拽缩放（最小 680×500，最大 900×900），8 个缩放手柄。全屏按钮跳转 `/chat?sessionId={id}`。

**会话历史面板**：加载/切换/删除会话，删除当前会话则自动创建新会话。

### 2.6 Auth 条件渲染汇总

| 组件/区块 | 未登录 | 已登录 |
|---|---|---|
| 首页内容 | 完整可见 | 完整可见 |
| Navbar 菜单 | 基础项 + 登录/注册 | 全部项 + 头像下拉 |
| AI 助手 | 提示登录，点击跳转 | 完整可用 |
| 公告数据 | ⚠ API 需认证，可能加载失败 | 正常加载 |

## 三、后端执行流程

### 3.1 认证架构

Sa-Token 拦截器配置（WebConfig.java）：
- 拦截 `/**`，放行 `/api/public/**`
- **但注解优先于拦截器**，部分 public 控制器有额外认证要求

| 控制器 | 路径前缀 | Sa-Token 注解 | 实际认证 |
|---|---|---|---|
| CoursePublicController | `/api/public/course` | 无 | **免登录** |
| CarouselPublicController | `/api/public/carousel` | 无 | **免登录** |
| CourseSubjectPublicController | `/api/public/course-subject` | 无 | **免登录** |
| ChapterSectionPublicController | `/api/public/chapter-section` | 无 | **免登录** |
| CourseCommentPublicController | `/api/public/comment` | 无 | **免登录** |
| **AnnouncementsPublicController** | `/api/public/announcements` | `@SaCheckRole("用户")` | ⚠ **需登录+用户角色** |
| **AnnouncementCategoriesPublicController** | `/api/public/announcement-categories` | `@SaCheckRole("用户")` | ⚠ **需登录+用户角色** |
| FileController | `/api/public/files` | `@SaCheckLogin` | ⚠ **需登录** |

### 3.2 轮播图接口

#### `GET /api/public/carousel/homepage`（免登录）

```
请求参数: limit（默认5，最小1）
│
┌─ 步骤1: 调用 getEnabledCarouselList()
│  ├── 构造 Carousel 条件: isDeleted=0
│  ├── carouselDao.queryAllByLimit(condition)
│  │   SQL: SELECT id, carousel_url, link_url, sort, is_deleted,
│  │              create_time, create_user, update_time, update_user
│  │        FROM carousel WHERE is_deleted = 0
│  │        ORDER BY sort ASC, create_time DESC
│  └── Java 侧再按 sort 升序排序（与 SQL 重复但保安全）
│
┌─ 步骤2: 截取前 limit 条
│
└─ 返回 Result<List<CarouselVO>>
    字段: id, carouselUrl, linkUrl, sort, isDeleted, createTime, updateTime
```

> Carousel 表结构详见 [数据库表结构汇总](../../公共参考/数据库表结构汇总.md)（carousel）

### 3.3 热门课程接口

#### `GET /api/public/course/hot`（免登录）

```
请求参数: limit（默认10，范围1-100，首页传8）
│
┌─ 步骤1: 查询所有已发布课程
│  ├── 构造 Course 条件: status=1
│  ├── courseDao.queryAllByLimit(condition)
│  │   SQL: SELECT id, teacher_id, subject_id, title, description, price,
│  │              lesson_num, duration_sum, cover, buy_count, view_count,
│  │              status, publish_time, create_time, create_user,
│  │              update_time, update_user
│  │        FROM course WHERE status = 1
│  │        ORDER BY create_time DESC
│  └── ⚠ 加载所有已发布课程到内存
│
┌─ 步骤2: 内存排序
│  └── 按 viewCount 降序排序
│
┌─ 步骤3: 截取前 limit 条
│
┌─ 步骤4: 填充 teacherName（去重批量查询）
│  ├── collect unique teacherIds → Set<Integer>
│  ├── 遍历每个唯一 teacherId → userDao.queryById(teacherId) → Map<Integer, String>
│  └── 从 map 填充所有 VO 的 teacherName（非逐课程 N+1，已去重优化）
│
└─ 返回 Result<List<CourseListVO>>
    字段: id, title, cover, subjectId, teacherId, teacherName, price,
          lessonNum, durationSum, status, buyCount, viewCount, publishTime,
          createTime, updateTime
```

> Course 表结构详见 [数据库表结构汇总](../../公共参考/数据库表结构汇总.md)（course）

**性能风险**：热门课程接口将所有已发布课程加载到内存后排序，课程量大时存在性能隐患。应改为 SQL `ORDER BY view_count DESC LIMIT #{limit}`。

### 3.4 课程分类树接口

#### `GET /api/public/course-subject/tree`（免登录）

```
无请求参数
│
┌─ 步骤1: 加载全部分类
│  └── courseSubjectDao.queryAllByLimit(new CourseSubject())
│      SQL: SELECT ... FROM course_subject ORDER BY create_time DESC
│
┌─ 步骤2: 按 parentId 分组
│  └── Map<Integer, List<CourseSubject>> groups = items.stream()
│          .collect(Collectors.groupingBy(CourseSubject::getParentId))
│
┌─ 步骤3: 递归构建树
│  ├── 从 parentId=0 的根节点开始
│  ├── 每个节点的 children = groups.get(node.id)
│  └── 递归处理每个子节点
│
└─ 返回 Result<List<CourseSubjectTreeVO>>
    字段: id, name, parentId, createTime, updateTime, children（递归）
```

> CourseSubject 表结构详见 [数据库表结构汇总](../../公共参考/数据库表结构汇总.md)（course_subject）

### 3.5 公告接口

#### `GET /api/public/announcements/latest`（⚠ 需登录 `@SaCheckRole("用户")`）

```
请求参数: count（默认5，范围1-20，首页传6）
│
┌─ Sa-Token 校验: @SaCheckRole("用户") → 需登录 + 用户角色
│
┌─ 步骤1: 查询最新已发布公告
│  ├── announcementsDao.getLatestAnnouncements(count)
│  │   SQL: SELECT id, category_id, title, publish_date, create_time
│  │        FROM announcements
│  │        WHERE publish_date IS NOT NULL
│  │        ORDER BY publish_date DESC
│  │        LIMIT #{count}
│  └── 仅返回简版字段（无 content）
│
┌─ 步骤2: 填充分类名称
│  └── categoryName 从 LEFT JOIN 或单独查询获取
│
└─ 返回 Result<List<AnnouncementSimpleVO>>
    字段: id, categoryId, categoryName, title, publishDate, isPublished, createTime
```

**⚠ 认证矛盾**：公告控制器位于 `/api/public/` 路径下但标注了 `@SaCheckRole("用户")`，意味着：
- 前端首页未登录时请求公告 API 会收到 401 错误
- "public" 在此场景下意为"普通用户可访问（非管理员/教师专属）"，而非"免登录"

#### 公告搜索 `GET /api/public/announcements/search`

```sql
WHERE publish_date IS NOT NULL
  AND (title LIKE CONCAT('%', #{keyword}, '%')
    OR content LIKE CONCAT('%', #{keyword}, '%'))
ORDER BY publish_date DESC
```

同时搜索标题和内容，与课程搜索（仅搜标题）不同。

#### 公告详情 `GET /api/public/announcements/{id}`

```sql
WHERE id = #{id} AND publish_date IS NOT NULL
```

仅返回已发布公告，含完整 `content` 字段。

> Announcements 表结构详见 [数据库表结构汇总](../../公共参考/数据库表结构汇总.md)（announcements）

### 3.6 课程列表/搜索接口

#### `GET /api/public/course/page`（免登录）

```
请求参数: PublishedCourseQueryDTO { title?, subjectId?, page?, size? }
│
┌─ 步骤1: 强制设置 status=1（仅已发布）
│
┌─ 步骤2: PageHelper 分页查询
│  ├── courseDao.queryAllByLimit(condition)
│  │   SQL: SELECT ... FROM course
│  │        WHERE status = 1
│  │        [AND title LIKE CONCAT('%', #{title}, '%')]  ← 模糊搜索
│  │        [AND subject_id = #{subjectId}]               ← 精确匹配
│  │        ORDER BY create_time DESC
│  └── PageHelper 自动添加 LIMIT/OFFSET
│
┌─ 步骤3: 填充 teacherName
│  └── ⚠ N+1 查询：每个课程单独 userDao.queryById(teacherId)
│
└─ 返回 Result<PageInfo<CourseListVO>>
    分页信息: list, total, pageNum, pageSize, pages, isFirstPage, isLastPage...
```

#### `GET /api/public/course/search`（免登录）

**与 `/page` 功能完全一致** — 调用相同的 `courseService.pagePublishedCourses(queryDTO)`，仅 Swagger 文档语义不同。

#### `GET /api/public/course/free`（免登录）

```
额外条件: price = 0（BigDecimal.ZERO 精确匹配）
SQL: ... AND price = 0
```

### 3.7 数据库查询汇总

| 接口 | SQL 核心条件 | 排序 | 分页 |
|---|---|---|---|
| 热门课程 | `status=1` | 内存排序 viewCount DESC | 截取 limit |
| 分类树 | 无条件 | create_time DESC（后 Java 重组树） | 无 |
| 轮播图 | `is_deleted=0` | sort ASC, create_time DESC | 截取 limit |
| 公告最新 | `publish_date IS NOT NULL` | publish_date DESC | LIMIT |
| 课程列表 | `status=1` + title LIKE + subjectId = | create_time DESC | PageHelper |
| 免费课程 | `status=1 AND price=0` | create_time DESC | PageHelper |
| 公告搜索 | `publish_date IS NOT NULL` + title/content LIKE | publish_date DESC | PageHelper |

### 3.8 Redis 缓存情况

**所有首页相关公共接口均无 Redis 缓存**，每次请求直接查询数据库。`redisService` 包存在于项目中但未被课程/轮播图/公告/分类 Service 的公共方法使用。

## 五、已知问题与风险点

> 跨模块系统级问题见 [公共参考-系统级已知问题与风险清单](../../公共参考/系统级已知问题与风险清单.md)，此处仅列本模块独有问题。

| # | 问题 | 严重度 | 说明 |
|---|---|---|---|
| 1 | **首页未复用 CourseCard.vue** | 低 | Home.vue 内联渲染课程卡片，缺少免费标签/悬停覆盖/auth 学习逻辑 |
| 2 | **轮播图详情接口不检查 is_deleted** | 低 | `GET /carousel/{id}` 可访问已删除的轮播图 |
| 3 | **分类树排序不一致** | 低 | SQL 按 create_time DESC，但子分类在 Java 中按 createTime ASC 排序，表现不一致 |
| 4 | **默认轮播文案硬编码** | 低 | 轮播图 title/description/buttonText 缺失时使用前端硬编码预设值，应后端管理 |

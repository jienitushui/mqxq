# 学生端公告政策功能 — 技术深度解析

## 一、功能概述

学生端公告政策模块提供平台公告的浏览、搜索、分类筛选与详情查看功能，涉及前端列表页、详情页、首页公告区，以及后端公共 API 与管理端 CRUD。

### 功能清单

| 功能 | 前端页面/组件 | 后端端点 | 认证要求 |
|---|---|---|---|
| 最新公告 | Home.vue 公告区 | `GET /api/public/announcements/latest` | ⚠ `@SaCheckRole("用户")` |
| 公告列表（分页） | AnnouncementList.vue | `GET /api/public/announcements/page` | ⚠ `@SaCheckRole("用户")` |
| 公告搜索 | AnnouncementList.vue | `GET /api/public/announcements/page`（keyword 参数） | ⚠ `@SaCheckRole("用户")` |
| 公告详情 | AnnouncementDetail.vue | `GET /api/public/announcements/{id}` | ⚠ `@SaCheckRole("用户")` |
| 分类筛选 | AnnouncementList.vue | `GET /api/public/announcements/page`（categoryId） | ⚠ `@SaCheckRole("用户")` |
| 同类推荐 | AnnouncementDetail.vue | `GET /api/public/announcements/category/{categoryId}` | ⚠ `@SaCheckRole("用户")` |
| 分类列表 | 两个页面 | `GET /api/public/announcement-categories/all` | ⚠ `@SaCheckRole("用户")` |
| 管理员 CRUD | 管理后台 | `/api/admin/announcements/*` | `@SaCheckRole("管理员")` |
| 管理员分类 CRUD | 管理后台 | `/api/admin/announcement-categories/*` | `@SaCheckRole("管理员")` |

### "已发布"判定规则

**无独立 `is_published` 字段**，以 `publish_date IS NOT NULL` 为唯一判定标准：
- `publish_date` 非空 → 已发布（对所有公共查询可见）
- `publish_date` 为 NULL → 草稿/已撤回（仅管理员可见）
- 发布操作：设置 `publish_date = 当前时间`
- 撤回操作：设置 `publish_date = NULL`

### ⚠ 认证矛盾

所有公告公共 API 位于 `/api/public/` 路径下（被 SaInterceptor 放行），但控制器类级别标注 `@SaCheckRole("用户")`，实际**需要登录 + 用户角色**。前端路由标记为 `requiresAuth: false`，导致未登录用户访问公告时可能收到 401 错误。

#### 数据加载流程

```
onMounted → getCategories(); getAnnouncementList()
│
├── getAnnouncementList()
│   ├── publicApi.getAnnouncementList(searchParams)
│   │   → GET /api/public/announcements/page?page=1&size=10&keyword=&categoryId=
│   ├── 多重 fallback 解包:
│   │   (response).data?.list || response.list || response.records || []
│   └── 赋值 announcements + total
│
└── getCategories()
    ├── publicApi.getAllAnnouncementCategories()
    │   → GET /api/public/announcement-categories/all
    ├── 多重 fallback 解包:
    │   (response).data?.list || (response).list || response || []
    └── 赋值 categories（用于下拉 + 快速筛选 + 分类名查找）

```

**⚠ 响应解包不一致**：列表页使用多重 fallback 解包 `response.data?.list || response.list || ...`，首页直接赋值 `announcements.value = data`，反映后端 `Result<T>` 响应结构在前端拦截器处理后不确定。

| 操作 | 触发方式 | 逻辑 |

### 3.2 公告列表（`GET /api/public/announcements/page`）

```
请求参数: AnnouncementPageQueryDTO { page(default 1), size(default 10), title?, categoryId? }
│
┌─ Sa-Token 校验: @SaCheckRole("用户")
│
┌─ 步骤1: 构建查询条件
│  ├── Announcements condition = new Announcements()
│  ├── title 非空 → condition.setTitle(title.trim())
│  └── categoryId 非空 → condition.setCategoryId(categoryId)
│
┌─ 步骤2: PageHelper 分页
│  └── PageHelper.startPage(page, size)
│
┌─ 步骤3: DAO 查询
│  └── announcementsDao.queryPublishedByLimit(condition)
│      SQL: SELECT Base_Column_List FROM announcements
│           <where>
│             AND publish_date IS NOT NULL           ← 仅已发布
│             [AND category_id = #{categoryId}]      ← 精确匹配
│             [AND title LIKE CONCAT('%',#{title},'%')]  ← 模糊搜索
│           </where>
│           ORDER BY publish_date DESC
│
┌─ 步骤4: 实体→VO 转换（⚠ N+1 查询）
│  └── convertToSimpleVO() → 每条记录:
│      announcementCategoriesDao.queryById(entity.getCategoryId())
│      → categoryName 查找
│
└─ 返回 Result<PageInfo<AnnouncementSimpleVO>>
    字段: id, categoryId, categoryName, title, publishDate,
          isPublished(始终true), createTime
    ⚠ 不含 content（SQL 使用 Base_Column_List 查询含 content，但 convertToSimpleVO() 在 Java 层不设置 content 字段）
```

### 3.3 公告详情（`GET /api/public/announcements/{id}`）

```
请求参数: id (path variable, min=1)
│
┌─ Sa-Token 校验: @SaCheckRole("用户")
│
┌─ 步骤1: DAO 查询
│  └── announcementsDao.queryPublishedById(id)
│      SQL: SELECT Base_Column_List FROM announcements
```

### 3.10 数据库表结构

> 数据库表结构详见 [公共参考-数据库表结构汇总](../../公共参考/数据库表结构汇总.md)

### 3.11 MyBatis SQL 汇总

**两套列清单**：
- `Base_Column_List`：含 content（用于详情查询）
- `Simple_Column_List`：不含 content（用于列表查询，避免大字段传输）

**两套 WHERE 片段**：
- `Query_Where_Clause`（管理员用）：无 publish_date 过滤，可查草稿
- `Published_Where_Clause`（公共用）：强制 `publish_date IS NOT NULL`

| SQL 方法 | 列集 | WHERE 片段 | 排序 |
|---|---|---|---|
| queryAllByLimit | Base | Query | create_time DESC |
| queryPublishedByLimit | Base | Published | publish_date DESC |
| queryPublishedById | Base | 手写 `id=? AND publish_date IS NOT NULL` | — |
| getLatestAnnouncements | Simple | 手写 `publish_date IS NOT NULL` + LIMIT | publish_date DESC |
| getPublishedByCategory | Simple | 手写 `category_id=? AND publish_date IS NOT NULL` | publish_date DESC |
| searchPublishedAnnouncements | Simple | 手写 `publish_date IS NOT NULL AND (title LIKE OR content LIKE)` | publish_date DESC |
| publishAnnouncement | — | `UPDATE SET publish_date=? WHERE id=?` | — |
| withdrawAnnouncement | — | `UPDATE SET publish_date=NULL WHERE id=?` | — |

### 列表页加载

```
AnnouncementList.vue onMounted

│  └── ⚠ 需 @SaCheckRole("用户")                       │
│  └── 返回 PageInfo<AnnouncementSimpleVO>              │
│                                                      │
│  GET /api/public/announcement-categories/all          │
│  └── ⚠ 需 @SaCheckRole("用户")                       │
│  └── 返回 List<AnnouncementCategoryVO>               │
│                                                      │
└──────────────────────────────────────────────────────┘
│
├── 渲染公告卡片列表 + 分类标签
└── 用户交互 → 搜索/筛选/翻页 → 重新调用列表 API
```

### 详情页加载

```
AnnouncementDetail.vue onMounted → route.params.id
│
├── GET /api/public/announcements/{id}
│   └── 返回 AnnouncementVO (含 content)
│
├── 成功后 → GET /api/public/announcements/category/{categoryId}

│
├── processedContent 处理: 图片URL包装 + 视频URL包装
└── v-html 渲染 + 点击图片弹大图
```

```
Home.vue onMounted (Promise.all 之一)
```

## 五、已知问题与风险点

> 跨模块系统级问题见 [公共参考-系统级已知问题与风险清单](../../公共参考/系统级已知问题与风险清单.md)，此处仅列本模块独有问题。

| # | 问题 | 严重度 | 说明 |
|---|---|---|---|
| 1 | **搜索全表扫描** | 中 | `LIKE '%keyword%'` 在 title+content 上无法使用索引，大表性能差 |
| 2 | **分类名唯一性无 DB 约束** | 中 | 仅服务层校验，并发下可能创建重名分类 |
| 3 | **前端搜索端点未使用** | 低 | `publicApi.searchAnnouncements` 为死代码，列表页用 `/page` + keyword 替代 |
| 4 | **详情页相关公告导航 Bug** | 中 | `router.push` 后立即调用 `getAnnouncementDetail()`，此时路由参数可能未更新 |
| 5 | **v-html XSS 风险** | 中 | 详情内容通过 `v-html` 渲染，仅包装图片/视频 URL，未对原始 HTML 做 sanitize |
| 6 | **视频 MIME 类型硬编码** | 低 | 所有视频 source 标签 type 固定为 `video/mp4`，非 MP4 格式可能无法播放 |
| 7 | **~~keyword 类型定义错误~~** | ~~低~~ 已修正 | ~~`AnnouncementSearchParams.keyword` 类型为 `number`，应为 `string`~~ 实际代码已为 `string`，此前文档描述有误 |
| 8 | **响应解包模式不一致** | 低 | 列表页/详情页多重 fallback 解包，首页直接赋值，反映对拦截器行为不确定 |
| 9 | **AnnouncementSimpleVO 的 isPublished 始终为 true** | 低 | 公共接口仅返回已发布公告，isPublished 字段冗余 |

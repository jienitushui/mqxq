## 一、概念说明

### 浏览量与浏览记录关系说明

#### 📊 核心概念

### 1. 浏览量（view_count）
- **存储位置**：`course` 表中的 `view_count` 字段
- **数据类型**：`int`，默认值为 0
- **含义**：课程被浏览的**总次数**（累计值）
- **特点**：
  - 每次有用户浏览课程详情页，浏览量 +1
  - 不区分用户，所有浏览都累加
  - 包括未登录用户的浏览（如果允许）

### 2. 浏览记录（course_view）
- **存储位置**：`course_view` 表
- **含义**：记录每个用户对每个课程的浏览行为
- **特点**：
  - 每个用户对每个课程**只有一条记录**（唯一索引：`user_id + course_id`）
  - 记录详细信息：浏览时间、IP地址、User-Agent等
  - 同一用户多次浏览同一课程时，只更新浏览时间，不新增记录

#### 🔗 两者关系

### 关系图

```
用户浏览课程详情页
    ↓
┌─────────────────────────────────────┐
│  CourseServiceImpl.getPublishedCourseDetail() │
└─────────────────────────────────────┘
    ↓
    ├─→ 记录浏览记录 (course_view)
    │   ├─ 如果用户已登录：创建/更新 course_view 记录
    │   └─ 每个用户每个课程只有一条记录
    │
    └─→ 更新浏览量 (view_count)
        └─ course.view_count = course.view_count + 1
           （每次浏览都 +1，不区分用户）
```

### 数据关系

| 维度 | 浏览量（view_count） | 浏览记录（course_view） |
|------|---------------------|----------------------|
| **存储位置** | `course` 表 | `course_view` 表 |
| **数据粒度** | 课程级别（每个课程一个值） | 用户-课程级别（每个用户每个课程一条记录） |
| **更新规则** | 每次浏览 +1 | 首次浏览创建，后续浏览更新 |
| **去重方式** | 不去重（所有浏览都计数） | 去重（同一用户同一课程只有一条） |
| **用途** | 展示课程热度、排序 | 用户浏览历史、统计分析 |

#### 📝 实现逻辑

### 1. 浏览记录创建/更新流程

**代码位置**：`CourseViewServiceImpl.recordOrUpdateCourseView()`

```java
// 1. 检查是否已存在该用户的浏览记录
CourseView condition = new CourseView();
condition.setCourseId(courseId);
condition.setUserId(userId);
List<CourseView> existingRecords = courseViewDao.queryAllByLimit(condition);

if (existingRecords.isEmpty()) {
    // 首次浏览：创建新记录
    return recordCourseView(createDTO);
} else {
    // 再次浏览：更新浏览时间
    CourseView record = existingRecords.get(0);
    record.setViewTime(new Date());
    courseViewDao.update(record);
}
```

**关键点**：
- 依赖唯一索引 `(user_id, course_id)` 保证每个用户每个课程只有一条记录
- 首次浏览创建记录，后续浏览只更新 `view_time`

### 2. 浏览量更新流程

**代码位置**：`CourseServiceImpl.getPublishedCourseDetail()`

```java
// 更新浏览数
Course updateCourse = new Course();
updateCourse.setId(courseId);
updateCourse.setViewCount(course.getViewCount() == null ? 1 : course.getViewCount() + 1);
courseDao.update(updateCourse);
```

**关键点**：
- 每次浏览都 +1，不区分用户
- 即使同一用户多次浏览，浏览量也会累加

#### 📈 数据统计

### 1. 浏览量统计

**用途**：
- 课程列表按浏览量排序（热门课程）
- 数据大屏展示课程热度
- 课程详情页展示浏览量

**统计方式**：
```sql
-- 直接读取 course.view_count
SELECT view_count FROM course WHERE id = ?
```

### 2. 浏览记录统计

**用途**：
- 统计独立访客数（去重后的用户数）
- 统计浏览趋势（按时间维度）
- 用户浏览历史记录

**统计示例**：
```sql
-- 统计某课程的独立访客数
SELECT COUNT(DISTINCT user_id) FROM course_view WHERE course_id = ?

-- 统计某课程的浏览记录总数（与view_count可能不同）
SELECT COUNT(*) FROM course_view WHERE course_id = ?

-- 统计某用户的浏览记录数
SELECT COUNT(*) FROM course_view WHERE user_id = ?
```

#### ⚠️ 重要区别

### 1. 数据一致性

**浏览量（view_count）**：
- 可能包含未登录用户的浏览
- 可能包含已删除的浏览记录对应的浏览量
- 是一个**累计值**，不会减少

**浏览记录（course_view）**：
- 只记录已登录用户的浏览
- 可以删除，删除后不影响浏览量
- 是**明细数据**，可以精确统计

### 2. 数量关系

```
浏览量（view_count）≥ 浏览记录数（course_view.count）
```

**原因**：
- 浏览量包括所有浏览（包括未登录用户）
- 浏览记录只包括已登录用户的浏览
- 同一用户多次浏览同一课程，浏览量会累加，但浏览记录只有一条

### 3. 实际场景

**场景1：用户A首次浏览课程1**
- `course.view_count`: 0 → 1
- `course_view`: 新增一条记录 (user_id=A, course_id=1)

**场景2：用户A再次浏览课程1**
- `course.view_count`: 1 → 2
- `course_view`: 更新已有记录的 `view_time`

**场景3：用户B首次浏览课程1**
- `course.view_count`: 2 → 3
- `course_view`: 新增一条记录 (user_id=B, course_id=1)

**场景4：未登录用户浏览课程1**
- `course.view_count`: 3 → 4
- `course_view`: 不记录（因为没有userId）

## 二、功能需求

### 浏览记录功能说明

#### 功能概述

浏览记录功能允许登录用户查看、管理自己的课程浏览历史，帮助用户快速回顾和访问之前浏览过的课程。

#### 主要功能

### 1. 浏览记录列表 (`/learning/history`)

**功能特点：**
- 分页显示用户的课程浏览记录
- 显示课程基本信息（封面、标题、描述、价格等）
- 显示浏览时间和浏览次数
- 支持课程名称搜索筛选
- 支持单条删除和批量删除
- 支持清空所有记录

**页面元素：**
- 页面标题和清空记录按钮
- 搜索筛选区域
- 批量操作提示（选中记录时显示）
- 记录列表表格
- 分页组件
- 空状态提示

**操作功能：**
- **查看课程**：跳转到课程详情页
- **查看详情**：查看浏览记录的详细信息
- **删除记录**：删除单条浏览记录
- **批量删除**：选中多条记录进行批量删除
- **清空记录**：清空所有浏览记录

### 2. 浏览记录详情 (`/learning/history/:id`)

**功能特点：**
- 显示浏览记录的详细信息
- 显示关联课程的完整信息
- 提供快捷操作按钮

**页面元素：**
- 返回按钮
- 记录基本信息（ID、课程ID、浏览时间等）
- 关联课程信息卡片
- 操作按钮区域

#### 后端数据格式

根据实际测试，后端返回的浏览记录数据格式如下：

```json
{
  "code": "200",
  "msg": "请求成功", 
  "data": {
    "total": 1,
    "list": [
      {

        "courseId": 20,

        "ipAddress": "127.0.0.1",
        "userAgent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36...",
        "createTime": "2026-01-17 14:02:22"
      }
    ],
    "pageNum": 1,
    "pageSize": 20,
    // ... 其他分页信息
  }
```

**注意：** 后端返回的浏览记录中不包含课程信息，需要前端根据 `courseId` 额外获取课程详情。

#### 前端处理逻辑

1. **获取浏览记录列表** - 调用 `/api/user/course-view/page` 接口
2. **提取课程ID** - 从浏览记录中提取所有唯一的 `courseId`
3. **批量获取课程信息** - 并发调用课程详情接口获取课程信息
4. **数据关联** - 将课程信息关联到对应的浏览记录
5. **前端筛选** - 支持按课程名称进行前端筛选

### 后端接口

1. **分页查询浏览记录**
   - `GET /api/user/course-view/page`
   - 参数：`pageNum`, `pageSize`, `courseId`（可选）

2. **查看浏览记录详情**
   - `GET /api/user/course-view/{id}`
   - 参数：浏览记录ID

3. **删除浏览记录**
   - `DELETE /api/user/course-view/{id}`
   - 参数：浏览记录ID

4. **批量删除浏览记录**
   - `DELETE /api/user/course-view/batch`
   - 参数：记录ID数组

5. **清空浏览记录**
   - `DELETE /api/user/course-view/clear`
   - 清空当前用户的所有浏览记录

#### 智能课程详情获取

项目实现了智能的课程详情获取机制：

```typescript
// src/utils/courseApi.ts
export const getCourseDetail = async (courseId: number): Promise<Course> => {
  const authStore = useAuthStore()
  
  if (authStore.isAuthenticated) {
    // 登录用户使用用户接口，可以获取个人化信息
    return await userApi.getCourseDetail(courseId)  // /api/user/course/{id}
  } else {
    // 未登录用户使用公共接口
    return await publicApi.getCourseDetail(courseId) // /api/public/course/{id}
  }
}
```

**优势：**
- 登录用户获取个人化的课程信息（包含学习进度、权限等）

- 统一的接口调用方式

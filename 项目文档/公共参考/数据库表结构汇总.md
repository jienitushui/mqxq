# 数据库表结构汇总

本文档汇集各功能模块中重复出现的数据库表定义，统一为 DDL 类型。各深度解析文档中对应表定义已替换为对本文件的引用。

---

## 一、用户认证相关

### user 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 用户ID |
| username | VARCHAR(255) | NOT NULL, UNIQUE | 用户名 |
| password | VARCHAR(255) | NOT NULL | BCrypt加密密码 |
| email | VARCHAR(255) | UNIQUE | 邮箱 |
| phone | VARCHAR(20) | | 手机号 |
| avatar | VARCHAR(500) | | 头像URL |
| name | VARCHAR(100) | | 昵称 |
| status | INT | DEFAULT 1 | 状态（1启用/0禁用） |
| create_time | DATETIME | | 创建时间 |
| update_time | DATETIME | | 更新时间 |

### role 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 角色ID |
| role_name | VARCHAR(50) | NOT NULL | 角色名（管理员/教师/用户） |
| role_code | VARCHAR(50) | | 角色代码（ADMIN/TEACHER/USER） |
| description | VARCHAR(200) | | 描述 |
| create_time | DATETIME | | 创建时间 |

### user_role 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 主键 |
| user_id | INT | FK → user.id | 用户ID |
| role_id | INT | FK → role.id | 角色ID |

索引：`idx_user_id`, `idx_role_id`

## 二、课程相关

### course 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 课程ID |
| teacher_id | INT | FK → user.id | 教师ID |
| subject_id | INT | FK → course_subject.id | 分类ID |
| title | VARCHAR(200) | NOT NULL | 课程标题 |
| description | TEXT | | 课程描述 |
| price | DECIMAL(10,2) | DEFAULT 0 | 价格 |
| lesson_num | INT | DEFAULT 0 | 课时数 |
| duration_sum | INT | DEFAULT 0 | 总时长(分钟) |
| cover | VARCHAR(500) | | 封面URL |
| buy_count | INT | DEFAULT 0 | 购买数 |
| view_count | INT | DEFAULT 0 | 浏览量 |
| status | INT | DEFAULT 0 | 状态（0未发布/1已发布） |
| publish_time | DATETIME | | 发布时间 |

### course_subject 表

| 字段 | 类型 | 约束 | 说明 |

| name | VARCHAR(100) | NOT NULL | 分类名 |
| parent_id | INT | DEFAULT 0 | 父分类ID（0为顶级） |
| sort_order | INT | DEFAULT 0 | 排序 |

### chapter 表

| 字段 | 类型 | 约束 | 说明 |

### section 表

| 字段 | 类型 | 约束 | 说明 |

## 三、订单相关

### orders 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 订单ID |
| order_no | VARCHAR(50) | UNIQUE | 订单号（时间戳+随机数） |
| user_id | INT | FK → user.id | 买家ID |
| goods_id | INT | | 商品ID（对应course.id） |
| goods_name | VARCHAR(200) | | 商品名称 |
| goods_img | VARCHAR(500) | | 商品图片 |
| goods_price | DECIMAL(10,2) | | 商品价格 |
| total_amount | DECIMAL(10,2) | | 订单总额 |
| status | VARCHAR(20) | | 订单状态（见公共文档-订单状态体系） |
| pay_no | VARCHAR(100) | | 支付流水号 |
| pay_time | VARCHAR(50) | ⚠ | 支付时间（VARCHAR类型，非DATETIME） |
| create_time | VARCHAR(50) | ⚠ | 创建时间（VARCHAR类型） |

⚠ `pay_time` 和 `create_time` 为 VARCHAR 类型，使用 `DATE()` 函数行为不确定。

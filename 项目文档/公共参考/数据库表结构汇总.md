# 数据库表结构汇总

本文档汇集各功能模块中重复出现的数据库表定义，统一为 DDL 类型。各深度解析文档中对应表定义已替换为对本文件的引用。

---

## 一、用户认证相关

### user 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 用户ID |
| username | VARCHAR(255) | NOT NULL | 用户名（即邮箱地址） |
| password | VARCHAR(255) | NULL | BCrypt加密密码 |
| name | VARCHAR(255) | NOT NULL | 昵称 |
| avatar | VARCHAR(255) | NULL | 头像URL |
| phone | VARCHAR(11) | NULL | 手机号 |
| status | INT | DEFAULT 1 | 状态（1启用/0禁用） |
| create_user | INT | NULL | 创建人ID |
| update_user | INT | NULL | 更新人ID |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

### role 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 角色ID |
| role_name | VARCHAR(255) | NULL | 角色名（中文：管理员/教师/用户） |
| role_code | VARCHAR(255) | NULL | 角色代码（ADMIN/TEACHER/USER） |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

### user_role 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 主键 |
| user_id | INT | NULL | 用户ID |
| role_id | INT | NULL | 角色ID |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

## 二、课程相关

### course 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 课程ID |
| teacher_id | INT | DEFAULT 0 | 教师ID |
| subject_id | INT | DEFAULT 0 | 分类ID |
| title | VARCHAR(50) | NOT NULL | 课程标题 |
| description | TEXT | NULL | 课程描述 |
| price | DECIMAL(10,2) | NOT NULL | 价格（0为免费） |
| lesson_num | INT | DEFAULT 0 | 课时数 |
| duration_sum | INT | DEFAULT 0 | 总时长(秒) |
| cover | VARCHAR(255) | NOT NULL | 封面URL |
| buy_count | INT | DEFAULT 0 | 销售数量 |
| view_count | INT | DEFAULT 0 | 浏览量 |
| status | TINYINT | DEFAULT 0 | 状态（0未发布/1已发布） |
| publish_time | DATETIME | NULL | 发布时间 |
| create_user | INT | DEFAULT 0 | 创建者ID |
| update_user | INT | NULL | 修改者ID |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

### course_subject 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 分类ID |
| name | VARCHAR(50) | NOT NULL | 分类名 |
| parent_id | INT | DEFAULT 0 | 父分类ID（0为顶级） |
| create_user | INT | NOT NULL | 创建者ID |
| update_user | INT | NULL | 修改者ID |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

### chapter 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 章节ID |
| course_id | INT | NOT NULL | 课程ID |
| title | VARCHAR(50) | NOT NULL | 章节标题 |
| create_user | INT | DEFAULT 0 | 创建者ID |
| update_user | INT | NULL | 修改者ID |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

索引：`idx_course_id`

### section 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 小节ID |
| chapter_id | INT | NOT NULL | 章节ID |
| course_id | INT | NOT NULL | 课程ID |
| title | VARCHAR(50) | NOT NULL | 小节标题 |
| content | TEXT | NULL | 小节内容 |
| video_url | VARCHAR(255) | NULL | 视频URL |
| duration | INT | DEFAULT 0 | 时长(秒) |
| status | TINYINT | DEFAULT 0 | 状态（0未发布/1已发布） |
| create_user | INT | DEFAULT 0 | 创建者ID |
| update_user | INT | DEFAULT 0 | 修改者ID |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

索引：`idx_chapter_id`, `idx_course_id`

## 三、订单相关

### orders 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 订单ID |
| order_no | VARCHAR(255) | NULL | 订单号（时间戳+随机数） |
| user_id | INT | NULL | 买家ID |
| goods_id | INT | NULL | 商品ID（对应course.id） |
| goods_name | VARCHAR(255) | NULL | 商品名称 |
| goods_img | VARCHAR(255) | NULL | 商品图片 |
| goods_price | DECIMAL(10,2) | NULL | 商品价格 |
| status | VARCHAR(255) | NULL | 订单状态（见公共文档-订单状态体系） |
| pay_no | VARCHAR(255) | NULL | 支付流水号 |
| pay_time | VARCHAR(255) | ⚠ NULL | 支付时间（VARCHAR类型，非DATETIME） |
| create_time | VARCHAR(255) | ⚠ NULL | 创建时间（VARCHAR类型） |

⚠ `pay_time` 和 `create_time` 为 VARCHAR 类型，使用 `DATE()` 函数行为不确定。

## 四、学习记录相关

### my_course 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 记录ID |
| user_id | INT | NOT NULL | 学生ID |
| course_id | INT | NOT NULL | 课程ID |
| order_id | INT | NULL | 关联订单ID |
| status | TINYINT | DEFAULT 0 | 状态（0已加入/1学习中/2已完成） |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

唯一索引：`uniq_user_course(user_id, course_id)`
索引：`idx_user_id`, `idx_course_id`, `idx_status`, `idx_my_course_order_id`, `idx_my_course_user_course`

### course_view 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 记录ID |
| user_id | INT | NOT NULL DEFAULT 0 | 浏览用户ID |
| course_id | INT | NOT NULL DEFAULT 0 | 课程ID |
| view_time | DATETIME | NOT NULL | 浏览时间 |
| ip_address | VARCHAR(45) | NULL | IP地址 |
| user_agent | VARCHAR(255) | NULL | 用户代理（浏览器信息） |
| create_time | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 记录创建时间 |

唯一索引：`uk_user_course(user_id, course_id)`
索引：`idx_course_id`, `idx_user_id`, `idx_view_time`

## 五、作业相关

### course_homework 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 作业ID |
| course_id | INT | NOT NULL | 课程ID |
| title | VARCHAR(200) | NOT NULL | 作业标题 |
| content | TEXT | NULL | 作业内容 |
| answer | TEXT | NULL | 参考答案 |
| score | DECIMAL(5,2) | DEFAULT 100.00 | 满分 |
| start_time | DATETIME | NOT NULL | 开始时间 |
| end_time | DATETIME | NOT NULL | 截止时间 |
| status | TINYINT | DEFAULT 0 | 状态（0未发布/1已发布） |
| create_user | INT | NOT NULL | 创建人（教师ID） |
| update_user | INT | NOT NULL | 修改人ID |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

索引：`idx_course_id`, `idx_status`, `idx_create_user`

### homework_submission 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 提交ID |
| homework_id | INT | NOT NULL | 作业ID |
| student_id | INT | NOT NULL | 学生ID |
| content | TEXT | NULL | 提交内容 |
| attachment_url | VARCHAR(500) | NULL | 附件URL |
| score | DECIMAL(5,2) | NULL | 得分 |
| max_score | DECIMAL(5,2) | NULL | 满分 |
| teacher_comment | TEXT | NULL | 教师评语 |
| grade_time | DATETIME | NULL | 批改时间 |
| grade_user | INT | NULL | 批改教师ID |
| status | TINYINT | DEFAULT 0 | 状态（0待批改/1已批改） |
| create_user | INT | DEFAULT 0 | 创建者ID |
| update_user | INT | NULL | 修改者ID |
| submit_time | DATETIME | NULL | 提交时间 |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

唯一索引：`uniq_homework_student(homework_id, student_id)`（同一作业每个学生只能提交一次）
索引：`idx_homework_id`, `idx_student_id`, `idx_status`, `idx_submit_time`

## 六、聊天相关

### chat_session 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 主键 |
| session_id | VARCHAR(32) | NOT NULL | 会话UUID |
| user_id | INT | NOT NULL DEFAULT 0 | 用户ID |
| title | VARCHAR(100) | NULL | 会话标题 |
| create_user | INT | NOT NULL | 创建人 |
| updater_user | INT | NOT NULL | 更新人 |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

索引：`session_id_index`, `user_id_index`, `update_time_index`

### chat_message 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 主键 |
| session_id | VARCHAR(32) | NOT NULL | 会话ID |
| user_id | INT | NOT NULL DEFAULT 0 | 用户ID |
| message_type | TINYINT | NOT NULL | 消息类型（1用户/2AI） |
| content | TEXT | NOT NULL | 消息内容 |
| params | TEXT | NULL | 附加参数（JSON） |
| message_order | INT | NOT NULL DEFAULT 0 | 消息顺序 |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

索引：`idx_session_id`, `idx_user_id`, `idx_create_time`, `idx_session_order(session_id, message_order)`

### course_comment 表

| course_id | INT | NOT NULL | 课程ID |
| teacher_id | INT | NOT NULL | 讲师ID |
| user_id | INT | NOT NULL | 用户ID |

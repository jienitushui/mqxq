## 一、Spring AI 配置与 Advisor 清单

### ChatClient 配置（学生端 AI 助手）

```java
this.chatClient.prompt()
    .system(SYSTEM_PROMPT)
    .advisors(new QuestionAnswerAdvisor(vectorStore, SearchRequest...))  // RAG检索
    .advisors(MessageChatMemoryAdvisor)                                  // 历史消息管理
    .user(question)
    .stream()
    .chatResponse()
```

### Advisor 完整清单

| Advisor | 作用 | 使用端 |
|---------|------|--------|
| MyLoggerAdvisor | 请求/响应日志 | 教师端（YuManus） |
| ReReadingAdvisor | 重读优化 | ⚠ 存在但未注册到任何端 |
| MessageChatMemoryAdvisor | Redis 历史消息管理 | 学生端 |
| SafeGuardAdvisor | 安全守卫 | 学生端 |
| QuestionAnswerAdvisor | RAG 向量检索增强 | 学生端（chat方法内联添加） |

### YuManus Agent 配置（教师端 AI 教案）

| 参数 | 值 | 说明 |
|------|------|------|
| maxSteps | 13 | 最大推理步数 |
| maxMessageHistory | 15 | 最大消息历史条数 |
| maxToolResponseLength | 2000 | 工具返回最大字符数 |
| SseEmitter timeout | 5 分钟 | SSE 连接超时 |
| 执行方式 | CompletableFuture.runAsync | 异步执行 |

### 两套 AI 系统对比

| 维度 | 学生端 ChatClient | 教师端 YuManus |
|------|-------------------|----------------|
| 架构 | Spring AI ChatClient | 自研 ReAct Agent |
| 模式 | 单轮 RAG 检索+生成 | 多步推理+工具调用 |
| 流式输出 | Flux\<ChatEventVO\> | SseEmitter |
| 会话管理 | Redis ChatMemory | 无持久化 |
| 工具调用 | CourseTools（2个） | 7个工具 |
| 向量检索 | Elasticsearch | 无 |

## 二、Elasticsearch 向量库配置

```yaml
spring:
  elasticsearch:
    uris: http://159.75.11.181:19200

  ai:
    dashscope:
      embedding:
        options:
          model: text-embedding-v3   # 阿里云通义千问 Embedding
          dimensions: 1024           # 向量维度
    vectorstore:
      elasticsearch:
        initialize-schema: true      # 启动时自动创建索引结构
        dimensions: 1024
```

数据同步：课程增删改时通过 `CourseVectorSyncService` 实时同步到向量库。

## 三、系统定时任务总览

| 任务 | Cron 表达式 | 说明 | 状态 |
|------|-------------|------|------|
| FileCleanupScheduledTask | `0 0 3 * * ?` | 每天凌晨3点清理 Agent 临时文件 | 启用 |
| ChatMessageSyncScheduledTask | `0 0 1 * * ?` | 每天凌晨1点同步 Redis 聊天消息到 MySQL | 启用 |
| CourseEmbeddingScheduledTask | `0 0 2 * * ?` / `0 0 * * * ?` | 全量/增量同步课程到向量库 | ⚠ 已注释（禁用） |

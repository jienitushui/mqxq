# 学习状态自动流转实现说明

> 学习状态体系定义及前后端映射差异见 [公共参考-学习状态体系](公共数据模型与基础配置.md#五学习状态体系my_course)。前端交互细节见 [学生端我的课程功能](../学生端功能说明/学生端我的课程功能-技术深度解析.md)。

## 概述

本次实现为在线教育平台添加了学习状态自动流转功能，使学习状态能够根据用户的学习行为自动更新，提升用户体验。

## 学习状态定义

> 学习状态定义详见 [公共参考-学习状态体系](公共数据模型与基础配置.md#五学习状态体系my_course)。以下为本实现涉及的三种状态概要：

- **0 - 已加入**：用户购买课程后加入，但还未开始学习
- **1 - 学习中**：用户正在学习课程
- **2 - 已完成**：用户完成了课程学习

## 状态流转规则

### 1. 已加入(0) → 学习中(1)

**触发时机：**
- 用户第一次观看课程任意章节/小节时
- 用户第一次提交作业时

**实现位置：**
- `CourseViewServiceImpl.recordCourseView()` - 记录观看时自动检查并更新
- `CourseViewServiceImpl.recordOrUpdateCourseView()` - 记录或更新观看时自动检查并更新
- `HomeworkSubmissionUserController.submitHomework()` - 提交作业时自动检查并更新

**实现逻辑：**
```java
// 只有状态为"已加入"(0)时才更新为"学习中"(1)
if (myCourse.getStatus() == 0) {
    myCourse.setStatus(1);
    myCourse.setUpdateTime(new Date());
    myCourseDao.update(myCourse);
}
```

### 2. 学习中(1) → 已完成(2)

**触发时机：**
- 用户提交作业后，系统自动检查是否满足完成条件
- 满足以下所有条件时自动更新：
  - 至少观看过一次课程内容
  - 完成所有课程作业（如果课程有作业的话）

**实现位置：**
- `HomeworkSubmissionUserController.submitHomework()` - 提交作业后自动检查并更新

**完成条件判断逻辑：**
```java
// 1. 检查是否有观看记录
boolean hasViewRecords = !courseViewDao.queryAllByLimit(viewCondition).isEmpty();

// 2. 检查作业完成情况
boolean homeworkCompleted = checkHomeworkCompletion(userId, courseId);
   - 如果课程没有作业，返回 true
   - 如果课程有作业，检查是否所有作业都已提交

// 3. 综合判断
return hasViewRecords && homeworkCompleted;
```

### 3. 已完成(2) → 学习中(1)

**触发时机：**
- 课程新增章节时自动触发
- 课程新增小节时自动触发
- 课程新增作业时自动触发
- 可通过手动调用 `PUT /api/user/my-course/progress` 接口更新状态

**实现位置：**
- `ChapterServiceImpl.createChapter()` - 创建章节时自动重置
- `SectionServiceImpl.createSection()` - 创建小节时自动重置
- `CourseHomeworkServiceImpl.createHomework()` - 创建作业时自动重置

**实现逻辑：**
```java
// 查询该课程所有状态为"已完成"(2)的学习记录
// 批量更新状态为"学习中"(1)
int resetCount = myCourseService.resetCompletedStatusToLearning(
    courseId, 
    "新增章节/小节/作业: " + title
);
```

## 核心实现

### 1. MyCourseService 接口新增方法

```java
/**
 * 检查并更新学习状态为"学习中"
 */
boolean checkAndStartLearning(Integer userId, Integer courseId);

/**
 * 检查并更新学习状态为"已完成"
 */
boolean checkAndCompleteCourse(Integer userId, Integer courseId);

/**
 * 判断课程是否学习完成
 */
boolean isCourseLearningCompleted(Integer userId, Integer courseId);

/**
 * 重置课程学习状态为"学习中"
 * 当课程内容更新（新增章节、小节、作业）时调用
 */
int resetCompletedStatusToLearning(Integer courseId, String reason);
```

### 2. MyCourseServiceImpl 实现

- `checkAndStartLearning()` - 检查状态为0时更新为1
- `checkAndCompleteCourse()` - 检查状态为1且满足完成条件时更新为2
- `isCourseLearningCompleted()` - 综合判断课程是否完成
- `checkHomeworkCompletion()` - 检查作业完成情况

### 3. CourseViewServiceImpl 集成

在以下方法中集成状态流转：
- `recordCourseView()` - 记录观看时触发
- `recordOrUpdateCourseView()` - 首次观看时触发

### 4. HomeworkSubmissionUserController 集成

在 `submitHomework()` 方法中集成：
- 提交作业后先检查并更新为"学习中"
- 然后检查是否满足完成条件，满足则更新为"已完成"

### 5. ChapterServiceImpl 集成

在 `createChapter()` 方法中集成：
- 创建章节后自动重置已完成用户的学习状态

### 6. SectionServiceImpl 集成

在 `createSection()` 方法中集成：
- 创建小节后自动重置已完成用户的学习状态

### 7. CourseHomeworkServiceImpl 集成

在 `createHomework()` 方法中集成：
- 创建作业后自动重置已完成用户的学习状态

## 技术特点

### 1. 事务安全
- 所有状态更新方法都使用 `@Transactional` 注解
- 确保数据一致性

### 2. 异常处理
- 状态流转失败不影响主业务（观看记录、作业提交）
- 使用 try-catch 捕获异常并记录日志

### 3. 幂等性
- 重复调用不会产生副作用
- 只在状态符合条件时才更新

### 4. 日志记录
- 详细记录状态变更日志
- 便于追踪和调试

## 使用示例

### 场景1：用户首次观看课程

```java
// 用户观看课程时，系统自动记录观看行为
CourseViewCreateDTO createDTO = new CourseViewCreateDTO();
createDTO.setUserId(userId);
createDTO.setCourseId(courseId);
courseViewService.recordCourseView(createDTO);

// 系统自动检查并更新状态：0 → 1
// 日志输出：用户{userId}首次观看课程{courseId}，学习状态已更新为'学习中'
```

### 场景2：用户提交作业

```java
// 用户提交作业
HomeworkSubmissionCreateDTO createDTO = new HomeworkSubmissionCreateDTO();
createDTO.setHomeworkId(homeworkId);
homeworkSubmissionService.submitHomework(createDTO, userId);

// 系统自动执行：
// 1. 如果状态为0，更新为1
// 2. 检查是否完成所有任务，如果完成则更新为2
// 日志输出：用户{userId}完成课程{courseId}所有学习任务，状态已更新为'已完成'
```

### 场景3：教师新增章节

```java
// 教师创建新章节
ChapterCreateDTO createDTO = new ChapterCreateDTO();
createDTO.setCourseId(courseId);
createDTO.setTitle("第五章：高级特性");
chapterService.createChapter(createDTO, teacherId);

// 系统自动执行：
// 1. 创建章节
// 2. 查找该课程所有状态为"已完成"的用户
// 3. 将这些用户的状态重置为"学习中"
// 日志输出：课程{courseId}新增章节，已重置{count}个用户的学习状态
```

### 场景4：教师新增作业

```java
// 教师创建新作业
CourseHomeworkCreateDTO createDTO = new CourseHomeworkCreateDTO();
createDTO.setCourseId(courseId);
createDTO.setTitle("期末考试");
courseHomeworkService.createHomework(createDTO, teacherId);

// 系统自动执行：
// 1. 创建作业
// 2. 将已完成该课程的用户状态重置为"学习中"
// 日志输出：课程{courseId}新增作业，已重置{count}个用户的学习状态
```

## 扩展建议

### 1. 更精细的完成条件

可以根据业务需求调整完成条件：
- 观看时长达到课程总时长的80%
- 必修章节全部观看完成
- 考试成绩达到及格线
- 课程评价已提交

### 2. 学习进度跟踪

建议添加学习进度字段：
```java
// 在 MyCourse 实体中添加
private Integer progress; // 学习进度百分比 0-100
```

### 3. 通知机制

状态变更时发送通知：
- 开始学习时发送欢迎消息
- 完成学习时发送祝贺消息和证书

### 4. 统计分析

基于状态流转数据进行分析：
- 平均学习时长
- 完成率统计
- 学习路径分析

## 注意事项

1. **性能考虑**：完成条件判断涉及多次数据库查询，建议添加缓存优化
2. **数据一致性**：确保状态更新与业务操作在同一事务中
3. **日志监控**：关注状态流转失败的日志，及时发现问题
4. **向后兼容**：保留手动更新状态的接口，支持特殊场景

```
                    (购买课程后)

                         ▼

                    (开始学习)

                         │ 1. 至少观看过一次课程内容

                         │

                         │
                         └─────────────┐
                                       │
                                       ▼

                                  (需要重新学习)
```

### 详细流程说明

#### 流程1：用户学习流程（正向流转）

```
步骤1: 用户购买课程
   └─> 状态: 0 (已加入)
        │
步骤2: 用户首次观看课程 或 首次提交作业
   └─> 自动触发状态检查
        └─> 状态: 0 → 1 (学习中)
             │
步骤3: 用户继续学习
   ├─> 观看课程内容 ✓
   ├─> 提交作业 ✓
   │
步骤4: 提交作业后，系统自动检查完成条件
   ├─> 检查是否有观看记录 ✓
   ├─> 检查是否完成所有作业 ✓
   └─> 如果都满足 → 状态: 1 → 2 (已完成)
```

#### 流程2：课程内容更新流程（反向流转）

```
步骤1: 教师新增课程内容
   ├─> 新增章节
   ├─> 新增小节
   └─> 新增作业
        │
步骤2: 系统自动查找该课程所有状态为"已完成"的用户
   └─> 批量更新状态: 2 → 1 (学习中)
        │
步骤3: 用户需要重新学习新增内容
   ├─> 观看新增章节/小节
   ├─> 完成新增作业
   │
步骤4: 完成新增内容后，系统再次检查
   └─> 如果满足完成条件 → 状态: 1 → 2 (已完成)
```

### 状态流转触发点总结

| 状态流转 | 触发时机 | 触发位置 | 自动/手动 |
|---------|---------|---------|----------|
| **0 → 1** | 首次观看课程 | `CourseViewServiceImpl.recordCourseView()` | ✅ 自动 |
| **0 → 1** | 首次提交作业 | `HomeworkSubmissionUserController.submitHomework()` | ✅ 自动 |
| **1 → 2** | 提交作业后检查完成条件 | `HomeworkSubmissionUserController.submitHomework()` | ✅ 自动 |
| **2 → 1** | 课程新增章节 | `ChapterServiceImpl.createChapter()` | ✅ 自动 |
| **2 → 1** | 课程新增小节 | `SectionServiceImpl.createSection()` | ✅ 自动 |
| **2 → 1** | 课程新增作业 | `CourseHomeworkServiceImpl.createHomework()` | ✅ 自动 |
| **任意** | 手动更新 | `PUT /api/user/my-course/progress` | 🔧 手动 |

## 触发接口列表

### 用户端接口（触发状态流转）

#### 1. 观看课程（触发 0 → 1）
- **接口路径**: `GET /api/user/course/{id}`
- **请求方式**: GET
- **接口说明**: 获取已发布课程详情，自动记录观看历史
- **触发逻辑**: 首次观看课程时，自动将状态从"已加入"(0)更新为"学习中"(1)
- **Controller**: `CourseUserController.getPublishedCourseDetail()`
- **Service**: `CourseServiceImpl.getPublishedCourseDetail()` → `CourseViewServiceImpl.recordOrUpdateCourseView()`

#### 2. 提交作业（触发 0 → 1 和 1 → 2）
- **接口路径**: `POST /api/user/homework-submission/submit`
- **请求方式**: POST
- **接口说明**: 学生提交作业
- **触发逻辑**: 
  - 如果状态为"已加入"(0)，自动更新为"学习中"(1)
  - 提交后自动检查完成条件，如果满足则更新为"已完成"(2)
- **Controller**: `HomeworkSubmissionUserController.submitHomework()`
- **请求体示例**:
```json
{
  "homeworkId": 1,
  "content": "作业内容",
  "attachmentUrl": "附件URL（可选）"
}
```

#### 3. 手动更新学习状态（任意状态流转）
- **接口路径**: `PUT /api/user/my-course/progress`
- **请求方式**: PUT
- **接口说明**: 手动更新课程学习状态
- **触发逻辑**: 支持手动设置任意状态值
- **Controller**: `MyCourseController.updateProgress()`
- **请求体示例**:
```json
{
  "courseId": 1,
  "status": 1  // 0-已加入, 1-学习中, 2-已完成
}
```

### 教师端接口（触发状态重置 2 → 1）

#### 4. 创建章节（触发 2 → 1）
- **接口路径**: `POST /api/teacher/chapter`
- **请求方式**: POST
- **接口说明**: 教师为课程创建新章节
- **触发逻辑**: 创建章节后，自动将该课程所有状态为"已完成"(2)的用户重置为"学习中"(1)
- **Controller**: `ChapterTeacherController.createChapter()`
- **请求体示例**:
```json
{
  "courseId": 1,
  "title": "第五章：高级特性",
  "orderNum": 5,
  "description": "章节描述（可选）"
}
```

#### 5. 创建小节（触发 2 → 1）
- **接口路径**: `POST /api/teacher/section`
- **请求方式**: POST
- **接口说明**: 教师为课程创建新小节
- **触发逻辑**: 创建小节后，自动将该课程所有状态为"已完成"(2)的用户重置为"学习中"(1)
- **Controller**: `SectionTeacherController.createSection()`
- **请求体示例**:
```json
{
  "chapterId": 1,
  "title": "5.1 小节标题",
  "orderNum": 1,
  "content": "小节内容",
  "videoUrl": "视频URL（可选）",
  "duration": 3600
}
```

#### 6. 创建作业（触发 2 → 1）
- **接口路径**: `POST /api/teacher/homework`
- **请求方式**: POST
- **接口说明**: 教师为课程创建新作业
- **触发逻辑**: 创建作业后，自动将该课程所有状态为"已完成"(2)的用户重置为"学习中"(1)
- **Controller**: `CourseHomeworkTeacherController.createHomework()`
- **请求体示例**:
```json
{
  "courseId": 1,
  "title": "期末考试",
  "description": "作业描述",
  "deadline": "2025-12-31 23:59:59",
  "maxScore": 100
}
```

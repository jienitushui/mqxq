# 数据大屏公共设计说明

> 本文档包含教师端和管理员端数据大屏的公共设计部分。
> 角色专属设计请参考：
> - [教师端数据大屏设计方案](../教师端功能说明/教师端数据大屏-设计方案.md)
> - [管理员端数据大屏设计方案](../管理员端功能说明/管理员端数据大屏-设计方案.md)

---

## 一、前端展示建议

### 1.1 技术选型
- **图表库**：ECharts / AntV G2 / Chart.js
- **大屏框架**：DataV / 自研响应式布局
- **实时更新**：WebSocket 或定时轮询（建议 30秒-1分钟）

### 1.2 布局设计
- **顶部**：核心指标卡片（4-6个）
- **左侧**：趋势图表（折线图、柱状图）
- **中间**：分布图表（饼图、环形图）
- **右侧**：排行表格、最近数据

---

## 二、性能优化建议

### 2.1 数据缓存
- 使用 Redis 缓存统计数据（缓存时间：5-10分钟）
- 避免频繁查询数据库

### 2.2 数据聚合
- 考虑使用定时任务预计算统计数据
- 存储到统计表中，减少实时计算

### 2.3 分页加载
- 排行数据支持分页
- 趋势数据支持日期范围选择

---

## 三、注意事项

1. **数据权限**：教师只能查看自己相关的数据，管理员可查看全部数据
2. **数据实时性**：建议使用缓存，避免频繁查询数据库
3. **日期范围**：支持自定义日期范围查询
4. **数据导出**：支持导出统计数据为Excel
5. **响应式设计**：适配不同屏幕尺寸
6. **性能优化**：大数据量时考虑分页或限制查询范围
